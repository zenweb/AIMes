# 2026-06-14 Review - 推荐公式权重合计 fail-loud

## 结论
- 未发现阻断问题。
- 推荐公式三项权重合计错误时，前端现在会以业务可读错误中断展示，避免不可审计推荐卡继续出现在用户路径里。

## 已检查
- `hasInvalidRecommendationScoreFormula` 只负责公式存在性、版本、说明、正数和有限数值。
- `hasInvalidRecommendationScoreFormulaWeightTotal` 单独负责三项权重合计必须等于 `1`。
- `loadData` 先检查基础公式，再检查权重合计，因此错误信息能精准落到 `后端推荐公式权重合计无效`。
- 单测确认异常公式不会渲染推荐卡、采纳按钮，也不会 emit `apply`。
- 真实 Chromium 定向用例确认合法 `40/40/20` 公式路径仍可通过。

## 残余风险
- 当前只校验权重合计，不评价 `40/40/20` 是否为业务最优权重。
- 工作树存在大量历史/并行改动，本 review 只覆盖本片相关文件。
