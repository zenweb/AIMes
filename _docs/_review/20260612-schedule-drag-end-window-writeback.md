# 2026-06-12 Review：排产拖拽结束时间回写

## 审查结论

通过本轮定向审查。拖拽保存成功后，本地甘特数据现在同时回写 `start_date`、`end_date` 与 `duration`，避免页面状态只部分更新。

## 风险点

- 当前修复只覆盖保存成功后的本地数据一致性；失败路径仍依赖现有 `loadData({ preserveError: true })` 恢复原始计划。
- 真实浏览器 E2E 校验的是前端发出的 reschedule 请求窗口，不代表后端数据库持久化链路已做端到端落库验收。

## 已验证证据

- 单测先红后绿：新增断言曾暴露 `end_date` 未同步，随后通过。
- 真实 dhtmlx E2E 无 retry 通过，成功/失败路径都校验请求时间窗口。

## 结论

本片提升了排产拖拽保存的正确性证据，符合“现有功能精品化优先”的 Core 约定。
