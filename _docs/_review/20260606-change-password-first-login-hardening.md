# Review: 首登强制改密精品化

## 结论

本轮改动聚焦既有安全关键路径，测试覆盖了首登强制改密的主要失败恢复分支，并修复了后端拒绝时的焦点恢复缺陷。

## 已核对

- 未新增功能范围，只硬化现有 `ChangePasswordPage`。
- 测试编码的是安全意图：失败时不得调用后端、不得登出、不得离开强制改密页。
- 真实浏览器 `login.spec.ts` 覆盖首登进入改密页、路由守卫、改密成功返回登录页。
- 定向 lint 和全量 unit coverage 均通过。

## 残余风险

- 本轮未新增后端 `change-password` 接口测试；后端安全闸门仍应由 Sprint 0/1 的后端基线继续覆盖。
- 发布 B 轨仍未关闭：Hosted CI、PostgreSQL/staging、攻击链人工验证、安全签字、14 天灰度观察仍缺证据。
