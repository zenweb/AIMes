> **版本**：基于 V1 设计文档 (2026-05-12)
> **适用范围**：AIMes V1 系列（v0.1.x）
> **更新策略**：开源版每次发布同步更新本文档；商业版能力变更不影响本文档

---

## 一句话定位

| 版本 | 定位 |
|------|------|
| **开源版（你正在用）** | 工厂可独立部署的「确定性」MES，AI 排产仅含规则引擎，演示用 RAG 占位 |
| **商业版** | 工厂级生产决策中枢，LLM 多目标优化、视觉质检、向量知识库、私有部署支持 |

## 该选哪个？

### 用开源版，如果你：
- 只需要基础 MES 功能（看板、工单、质量、设备）
- AI 排程「能用就行」（规则引擎够用）
- 单机或单工厂部署
- 不介意自助使用 + GitHub Issues 支持

### 用商业版，如果你：
- 多车间 / 多工厂协同排程
- 需要 **LLM 多目标优化**（不仅快，还要兼顾交期 / 利用率 / 换型 / 平衡）
- 排程结果要能从历史数据**自动学习**
- 视觉质检要**真实可用**（不仅是占位）
- 需要 K8s / 多租户 / SLA 支持
- 法务要求**单点联系 + 责任主体**

## FAQ

**Q：开源版会被「砍功能」吗？**
A：不会。开源版功能边界已在 V1 设计文档冻结，未来版本只增不减。商业版增量是上面表里 ❌ 的部分。

**Q：可以基于开源版二次开发然后商用吗？**
A：可以。Apache 2.0 许可允许商用，包括闭源衍生。但请注意保留 `LICENSE` 与 NOTICE。

**Q：贡献的 PR 会被合并到商业版吗？**
A：开源版的 PR 我们正常评估。商业版是独立闭源代码库，不会包含外部贡献。

**Q：开源版能升级到商业版吗？**
A：可以。商业版是开源版的**超集**，数据库/API 兼容。升级路径：`docker compose down` → 替换镜像 → `docker compose up -d`。详细迁移文档随商业版交付。
