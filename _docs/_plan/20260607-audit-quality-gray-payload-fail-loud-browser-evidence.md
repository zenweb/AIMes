# 2026-06-07 Plan - AuditDecisionReplayPanel 质量灰度决策坏载荷 Chromium 证据

## 成功标准

- 真实 Chromium 中可构造质量灰度决策接口返回 200 非数组载荷。
- 页面必须展示 fail-loud 告警，包含 `质量灰度决策加载失败` 和 `后端返回非数组审计载荷`。
- 基础回放卡片必须仍可见。
- 不扩展新功能，不改变发布闸门状态。

## 执行

1. 读取质量知识证据同步工具、审计回放组件和现有单元/e2e。
2. 确认已有接口失败 Chromium 证据，但缺少 200 非数组坏载荷证据。
3. 为质量知识证据读取增加运行时数组校验。
4. 新增工具单元测试覆盖质量灰度决策非数组载荷。
5. 新增真实 Chromium e2e 覆盖质量灰度决策非数组载荷。
6. 跑定向单元、组件定向单元、定向 e2e 并记录结果。
