# 2026-06-07 Plan - AuditDecisionReplayPanel 业务落库审计列表坏载荷 Chromium 证据

## 成功标准

- 真实 Chromium 中可构造业务落库审计列表返回 200 且 `items` 非数组。
- 页面必须展示 fail-loud 告警，包含 `业务落库审计加载失败` 和 `后端返回非数组审计载荷`。
- 基础回放卡片必须仍可见。
- 不扩展新功能，不改变发布闸门状态。

## 执行

1. 读取业务落库审计读取函数、现有单元和 e2e。
2. 确认已有接口失败、详情失败、详情载荷损坏、载荷缺失和未知资源证据，但缺少列表 `items` 非数组证据。
3. 先写组件单元和真实 Chromium e2e。
4. 观察红灯：单元与真实浏览器均暴露 `items.map is not a function`。
5. 为业务落库审计列表读取增加运行时数组校验。
6. 跑组件定向单元和定向 e2e 并记录结果。
