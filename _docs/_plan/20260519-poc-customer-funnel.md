# 20260519 POC 客户漏斗启动方案

> v3.0 路线 Phase C 配套：在 Phase A/B 写代码的同时，并行启动 POC 客户寻找。
> 决策周期 3-6 个月，越早启动越好，不该等 demo 完成。
>
> 本文档不是承诺，是**当前最佳猜测**。客户漏斗是销售实践，会随接触一线信号迭代。

## 一、目标客户画像

### 硬性条件（不满足直接 pass）

| 维度 | 标准 | 为什么 |
|------|------|--------|
| **行业** | 离散制造（装配 / 机加工 / 电子组装 / 注塑 / 五金） | 排产场景天然适用；流程行业（化工 / 钢铁）排产逻辑不同 |
| **生产模式** | 多品种小批量 + 插单频繁 | 这是 Agent 价值最明显的场景，单一品种连续生产 Agent 没用 |
| **工单规模** | 月活跃工单 ≥ 30 单 | 低于这个量级 A/B 数据没说服力 |
| **数据基础** | 已有 MES 或 ERP，至少能导出工单/BOM/工艺路线 | 没数据基础 POC 跑不起来，前期数据搬运成本压垮项目 |
| **APS 现状** | 无 APS 或 APS 用不起来（被绕过 / 维护停滞 / 不准） | 有强 APS 的客户购买决策门槛高，不是 POC 优先 |

### 软性偏好（加分项，不是必须）

- 年营收 1-10 亿（中小型，决策链短）
- 厂长 / 生产副总 是决策人（不是 IT 一票否决）
- 已有数字化转型预算（接受新工具的心理门槛低）
- 已经在用国产 ERP / MES（用 SAP 的客户对国产 AI 接受度普遍较低）
- 在长三角 / 珠三角 / 成渝（线下踏勘成本可控）

### 反向画像（明确放弃）

- ❌ 大型集团（决策慢、采购流程重、与现有 SAP 集成难）
- ❌ 流程行业（化工、钢铁、食品）
- ❌ 单品种大批量连续生产（Agent 价值低）
- ❌ 没有 IT 配合人员的纯传统工厂（POC 部署对接不下来）
- ❌ 把 AI 当 KPI 的国企（要的是上线照片不是真实业务价值）

## 二、价值主张话术

### 一句话定位

> "我们的 AI 调度员把交期达成率提升 X%，免费给你试 8 周，不行就走。"

### 客户为什么应该听

```
传统排产员                调度员 Agent
───────────              ───────────
靠经验 / 拍脑袋            多策略候选 + 量化对比
单一目标（按排序）          多目标（交期 + 稼动 + 换型）
插单后重排靠加班            插单 → 自动建议 → 一键采纳
新人上手要 6 个月          标准化建议 + 解释
排错了没人记账             采纳/拒绝/效果回写
```

### 客户最常问 + 标准回答

**Q: AI 排产我们 N 年前就听过，你和他们什么区别？**
A: 三件事不同。第一，可解释——每个推荐附带"为什么选这个 / 牺牲了什么"。第二，可采纳——人审核后才执行，AI 不直接动产线。第三，可追溯——所有建议、采纳、效果回写都有记录，不是黑盒。

**Q: 我们已经有 ERP / MES 了，你这个怎么对接？**
A: 我们不替代你的 ERP/MES。我们读取工单/BOM/工艺路线（标准 Excel 或 API），输出排产建议（你看了再下发）。集成 4 周，对生产无干扰。

**Q: 你能保证提升 X%？**
A: 不能保证。POC 阶段我们对你现有 N 工单做 A/B 对比，跑出真实改善数字。如果不显著，POC 结束时坦白告诉你"在你的场景下 Agent 不显著优于现有方法"——这个坦白态度本身就是我们和别家不同的地方。

**Q: 数据安全怎么办？**
A: 我们部署在你内网，数据不出厂区。POC 协议明确"数据使用权仅限 AIMes 产品改进，去标识化后可用于案例发表，但需经你审核"。

**Q: POC 完了你怎么收费？**
A: POC 期间免费。POC 后如果你想继续用，按工单量年费制。具体定价 POC 结束后再谈，我们和你一起看价值定价。

## 三、POC 提案模板

### 我们提供（免费）

- AIMes V1 完整部署到你的内网
- 调度员 Agent + 排产优化 Skill 接入你的工单数据
- 8 周陪跑：每周一次远程评审 + 1-2 次现场支持
- A/B 对比报告：基线（你现有方法）vs Agent 推荐
- 部署文档 + 操作培训 + 报告解读

### 我们要求（数据使用权）

- POC 期间产生的脱敏运营数据用于 AIMes 产品改进
- 案例发表权（去标识化或需经你审核同意）
- POC 结束后的反馈访谈（1-2 小时）

### 客户配合（最低门槛）

- 1 名 IT 对接人（负责数据导出 / 部署支持）
- 1 名生产管理对接人（排产员或生产经理，负责评估 Agent 推荐）
- 提供测试环境工单数据（脱敏后即可，不需要真实生产环境）
- 8 周内每周 1 小时评审会

### 关键时间线（8 周）

| 周 | 阶段 | 动作 | 客户参与度 |
|----|------|------|-----------|
| W1 | 启动 | 现场踏勘 + 数据评估 + 部署计划 | 高 |
| W2 | 部署 | 内网部署 + 数据导入 + 基线测算 | 中 |
| W3-4 | 调通 | Agent 推荐跑通 + 演示 + 问题反馈 | 中 |
| W5-6 | 跑数据 | A/B 对比 + 真实工单评审 | 高 |
| W7 | 调优 | 根据反馈调整策略权重 | 中 |
| W8 | 报告 | A/B 报告交付 + 价值评估 + 后续讨论 | 高 |

### 退出条款

任一方在第 W4 周末有权终止 POC，不追责。这是为了双方都不勉强——AI 不适合所有场景，我们也不适合所有客户。

## 四、外联渠道（按 ROI 排序）

### 第 1 优先级：个人人脉激活

**为什么排第一**：信任成本最低，决策最快，POC 配合度最高。

**动作清单**：
- 列出 30 个最可能的人脉（前同事、同学、行业朋友）
- 每个人发一句话定位 + POC 提案附件
- 不群发，每个人发 1 条短消息：「最近在做一个东西，想听听你的反馈，方便聊 15 分钟吗？」
- 目标：第 1 个月内 5-10 次对话

### 第 2 优先级：行业社群投放

**为什么排第二**：信任成本中等，但触达面广。

**渠道**：
- 工业互联网联盟（各地）
- 各地智能制造协会
- 知乎"智能制造""MES"话题
- 公众号"工业互联网研习社""智造甲方俱乐部"等
- 制造业 IT 群（很多群都有，问周围人讨群链接）

**动作清单**：
- 写 2 篇内容：
  1. 《我们为什么放弃做 AI MES 平台，转做单点调度员 Agent》（战略故事）
  2. 《从固纬电子 50% 缺陷率改善看制造业 Agent 落地》（行业故事）
- 在 3-5 个相关社群分享
- 文末附 POC 邀请

### 第 3 优先级：内容营销长尾

**为什么排第三**：见效慢但持续累积。

**动作清单**：
- 公众号 / 知乎每月 1-2 篇
- 主题：单 Agent 设计、A/B 框架、行业对标解读
- 每篇内容 CTA 都引到 POC 邀请

### 第 4 优先级：行业会议

**为什么排第四**：触达高，但成本高且周期长。

**动作清单**：
- 关注 2026Q3-Q4 制造业相关会议（汉诺威、工博会、智能制造峰会）
- 不强求演讲，先去学习 + 现场加微信
- 一次会议出 5-10 个有效线索就值

### 第 5 优先级（暂不优先）：政府渠道

**为什么排第五**：流程慢、合规要求高，对单人/小团队不友好。
**动作**：不主动追，遇到了再看。

## 五、漏斗转化目标（前 3 个月）

> 数字是当前最佳猜测，第 1 个月后根据真实信号迭代。

```
触达 (人脉激活 + 社群投放)        100 人
        ↓ 转化 30%
有效对话                         30 次
        ↓ 转化 30%
深度评估（现场踏勘）              10 家
        ↓ 转化 30%
POC 候选                         3 家
        ↓ 转化 30%
POC 成交                         1 家  ← 目标
```

**校准信号**：
- 第 1 个月内 3 次有效对话 → 漏斗启动正常
- 第 2 个月内 1 家深度评估 → 漏斗有动力
- 第 3 个月内 1 家 POC 候选 → 节奏对得上 Phase B 完成

如果第 1 个月 3 次有效对话都做不到，重审：
- 价值主张话术不对路？（直接问对话过的人）
- 渠道选错？
- 时机不对？（行业淡季 / 客户预算锁定期）

## 六、关键风险

### 风险 1：POC 客户拿了 demo 不付费

**症状**：POC 完客户感谢一句话，没有后续。
**护栏**：
- POC 协议第一条就写"案例发表权 + 反馈访谈"——即使不付费，也能产出案例和洞察
- POC 第 W6 周开始铺垫商业化讨论，不让客户在 W8 措手不及
- 不和"明显不会付费"的客户做 POC（POC 是销售机会筛选器，不是公益）

### 风险 2：POC 跑出来 OTD 改善不显著

**症状**：A/B 对比 ΔOTD 在置信区间下不显著，或负向。
**护栏**：
- v3.0 路线图已内置"如何发现噪音"机制——这种结果是预期内的
- 报告坦白"在你的场景下 Agent 不显著优于现有方法"，这是诚信资产
- 反思：是 demo 数据脱离现实？是策略权重不适合？是场景选错？写在内部复盘

### 风险 3：单一 POC 数据点说服力不够

**症状**：1 家成功了，但行业不买账。
**护栏**：
- 第 1 家 POC 完成后，立即启动第 2-3 家（不等第 1 家完美）
- 多个 POC 数据点比 1 个完美 POC 数据点更可信
- 如果第 1 家失败也别气馁，"失败案例 + 复盘"也是内容资产

### 风险 4：销售工作挤占工程时间

**症状**：客户漏斗占用时间太多，Phase A/B 进度被拖
**护栏**：
- 每周固定时间窗口给销售（如周二下午 + 周五上午），其他时间封闭写代码
- POC 启动期允许时间分配 70% 工程 / 30% 销售
- 出现 POC 候选后再调整为 50/50
