# 2026-06-21 Plan - 排产页人员替班放行读回

## 目标
- 员工页完成补证改派放行后，AI 排产页刷新或新会话仍能从后端读到放行结果。
- 已 `released` 的阻断不能继续生成停工复核事件或建议。
- 已 `approved` 的替班记录必须作为已闭环人员事件进入排产队列。

## 步骤
1. 审计排产页人员事件来源。
2. 确认事件队列启动态仍可能依赖本地证据。
3. 增加启动后端人员证据读回。
4. 后端成功时以后端为准，过滤 `released` 阻断。
5. 增加 stale 本地阻断和 released+approved 两类单测。
6. 构建并用真实浏览器验证新会话排产页。

## 成功标准
- 后端人员证据接口返回 200。
- 排产页显示人员替班已确认。
- 排产页不显示过期停工复核事件。
- 页面无 Offline demo、加载失败或人员资质证据刷新失败文案。
