# AIMes V1 功能深化脑暴清单

> 日期：2026-05-19
>
> 目的：把当前“模块能演示”的 V1 功能面，转成“AI MES 能打动现场”的深化 backlog。
>
> 执行口径：不平均加厚所有模块，优先围绕“调度员 Agent + 排产优化 Skill + 交期达成率改善”形成闭环。

---

## 结论先行

当前系统已经有完整 MES 功能面，但很多模块仍停留在“列表 + 详情 + demo fallback + 少量操作”。下一阶段不应继续横向堆模块，而应把现有模块串成一条可讲业务结果的主线：

```text
新工单 / 插单 / 设备故障 / 缺料
        ↓
风险识别
        ↓
调度员 Agent 生成多方案
        ↓
人审核采纳
        ↓
生产执行 / 采购 / 设备 / 质量联动
        ↓
OTD 改善复盘
```

第一优先级是让系统回答一个老板问题：

> “用了 AIMes 后，交期达成率到底提高了多少？为什么？”

## P0 主线：调度员 Agent 工作台

### 目标

把 `AI 排产` 从“甘特图页面”升级成“调度员每天打开的工作台”。

### 必须具备

- 工单池：待排、已排、风险、插单。
- 排产方案：基线方案、Agent 推荐方案、人工调整方案。
- 影响分析：OTD、延期订单、设备利用率、换线时间、缺料风险。
- 解释面板：为什么推荐这个方案，牺牲了什么，保护了什么。
- 采纳/拒绝：记录原因，进入反馈数据集。
- 执行追踪：采纳后实际完成情况回写，形成复盘。

### 产品脑暴

1. **“一键解释这个排产”**
   - 对任意任务条解释：交期、设备、前置工序、缺料、瓶颈。
   - 输出结构：约束命中、选择原因、风险提示、可替代方案。

2. **“插单前先算账”**
   - 插入一张急单前，显示被影响的工单、延期小时数、换线增加、缺料变化。
   - 给 3 个选项：强插、加班、换设备/外协。

3. **“调度员 A/B 复盘”**
   - 同一批工单显示人工基线 vs Agent 推荐。
   - 强制展示 OTD 改善、延期订单减少、换型成本变化。

4. **“锁定期保护”**
   - 8 小时内任务默认锁定。
   - Agent 只能建议，不直接改动。
   - 解锁必须写原因，进入审计。

### 验收标准

- 能在 demo 数据上展示“交期达成率改善 X%”。
- 任意推荐方案都有可读解释。
- 采纳/拒绝会留下业务原因和审计记录。
- 插单、设备故障、缺料 3 个场景都能触发重排建议。

## Demo 路径

建议售前演示按这条线走，不要逐个菜单点：

1. 打开生产概览：显示今日风险和排产状态。
2. 进入风险预警：发现急单/缺料/设备故障。
3. 进入 AI 排产：Agent 给出 3 个方案。
4. 查看解释：为什么推荐方案 B。
5. 采纳方案：写入反馈。
6. 进入生产报工：执行某个工序。
7. 上报异常：触发风险变化。
8. 回到排产：生成重排建议。
9. 打开报表：展示 OTD 改善。
