# AIMes V1 功能深化脑暴清单

> 版本定位 | 2026-05-23 复核
>
> 本文档是 **V1.5 AI 功能深化当前主线** 的活跃实施清单。V1 已完成 MES 功能面，V1.5 的目标是在现有演示闭环上继续把 AI 决策、证据链、执行包、权限审计和真实量化逐步后端化。
>
> `_docs/ai-mes-roadmap.md` 已改为 V3 远期研究，不再覆盖本文档的当前执行口径。

> 日期：2026-05-19
>
> 目的：把当前"模块能演示"的 V1 功能面，转成"AI MES 能打动现场"的深化 backlog。
>
> 执行口径：不平均加厚所有模块，优先围绕"调度员 Agent + 排产优化 Skill + 交期达成率改善"形成闭环。

---

## 结论先行

当前系统已经有完整 MES 功能面，但很多模块仍停留在"列表 + 详情 + demo fallback + 少量操作"。下一阶段不应继续横向堆模块，而应把现有模块串成一条可讲业务结果的主线：

```text
新工单 / 插单 / 设备故障 / 缺料
        ↓
风险识别
        ↓
调度员 Agent 生成多方案
        ↓
人审核采纳
        ↓
生产执行 / 采购 / 设备 / 质量联动
        ↓
OTD 改善复盘
```

第一优先级是让系统回答一个老板问题：

> "用了 AIMes 后，交期达成率到底提高了多少？为什么？"

|------|----------|----------|------------|
| 生产概览 | KPI、设备状态、今日排产、物料预警、质量概览 | 汇总可看，但缺行动入口 | 指挥中心 |

| 质量闭环 | KPI、SPC、检验批次、根因分析 demo | 有 AI 感，但未闭环到返工/排产 | 质量事件闭环 |

| 审计日志 | 日志列表/详情 | 合规底座 | AI 决策回放 |
| AI 生产助手 | 聊天、来源、demo 回答、LLM 状态 | 有入口，动作能力弱 | 可执行助手 |

## Sprint 推进记录摘要

### Sprint A：排产可讲数字 (2026-05-19)

1. 基线 vs Agent OTD 对比面板（demo: 82% → 96%，+14%）
2. 插单影响分析（WO-RUSH-9001 延期/换线/缺料）
3. 采纳/拒绝原因反馈条
4. e2e: Scheduling 排产甘特图 3 条用例

### Sprint B：三类事件触发 Agent (2026-05-19)

1. 缺料、设备故障、急单插单三类事件重排队列
2. 每类事件可生成 Agent 重排建议
3. 接入 risk/dashboard 风险数据映射层
4. 事件建议接入采纳/拒绝反馈链路
5. e2e: 三类事件 + 采纳反馈

### Sprint C：执行闭环 (2026-05-19~21)

1. 生产报工完工回写 + 排产进度更新
2. 异常上报 → 异常管理 → 风险联动
3. 缺料采购协同（加急单、替代料、收货回写）
4. 供应风险控制塔 + 供应商 SLA 选优
5. OTD 证据链：AI 排产、风险处置、质量 CAPA、POC 签署统一来源
6. e2e: 采购 4 条 + 生产 2 条 + 跨模块 69 passed

### Sprint D：可销售演示 (2026-05-20~23)

1. OTD 改善复盘报告（30 单数据集：82%→96%）
2. 5 分钟 Demo 路径 + 彩排确认闭环
3. POC 评估模板（97/100→100/100）
4. 客户真实工单导入样例 + 设备故障数据
5. POC 复盘会评分表签署
6. 统一 OTD 证据链 → Agent 治理 → 审计回放
7. OTD 证据治理 + 工程/人员证据入链
8. e2e: 全模块 219+ passed

### 2026-05-23 追加推进

- AI 助手可执行动作扩展：异常处置包、客户承诺包、工程约束复核包、齐套包、停机包
- 替代料工程确认 → 排产约束释放
- 人员资质临期替班闭环（7+ e2e）
- 条码质量门 + 扫码返工 + 复验放行（65+ 跨模块 passed）
- AI 助手 RAG 引用治理 → Agent 治理待办

## Demo 路径

建议售前演示按这条线走，不要逐个菜单点：

1. 打开生产概览：显示今日风险和排产状态
2. 进入风险预警：发现急单/缺料/设备故障
3. 进入 AI 排产：Agent 给出 3 个方案
4. 查看解释：为什么推荐方案 B
5. 采纳方案：写入反馈
6. 进入生产报工：执行某个工序
7. 上报异常：触发风险变化
8. 回到排产：生成重排建议
9. 打开报表：展示 OTD 改善
