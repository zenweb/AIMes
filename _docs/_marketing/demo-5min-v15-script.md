## Why no mp4 in this branch

This branch ships the **complete recording asset bundle** but not the final mp4:

- ✅ Script: this file (current real numbers)
- ✅ Subtitles: `demo-5min-v15.srt` (current real numbers)
- ✅ Storyboard screenshots: `demo-screenshots/01..05*.png` (5 真实页面截图, 1440×900, generated by Playwright against real build, 691KB total)
- ✅ Reproducible data pipeline: `scripts/run-ab-comparison.ps1` → `latest-ab-report.json` → frontend
- ❌ Final mp4 + voice-over track

The mp4 production requires recorder + microphone + voice talent + post-production tooling that aren't available in the local engineering loop. **All AI-generated content in this asset bundle uses real numbers from the actual engine** — there is no hardcoded marketing fiction. Record the mp4 externally with this script as the canonical source of truth.

## Versioning rule

Whenever `latest-ab-report.json` changes (seed change, dataset extension, Monte Carlo wired in, etc.), bump this script's "Current verified data point" section and regenerate `demo-5min-v15.srt`. Do not record a new mp4 against stale numbers.
