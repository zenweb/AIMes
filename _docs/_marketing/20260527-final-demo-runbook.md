# AIMes Final 5-Minute Demo Runbook

> Date: 2026-05-27  
> Audience: product review, customer demo, internal acceptance  
> Goal: demonstrate a professional AI MES where backend actions are traceable, real writes are persisted, and evidence can be replayed.

## 0. Setup

Preferred visual demo mode:

```powershell
cd C:\AIWorks\AIMes\v1\src\frontend
$env:VITE_OFFLINE_DEMO='true'
npm run preview
```

Use offline demo mode for screenshot-safe demos where the backend is not running. It prevents preview pages from issuing `/api` and `/hubs` requests and keeps visual smoke clean.

Use normal e2e/backend mode when proving API behavior:

```powershell
cd C:\AIWorks\AIMes\v1
dotnet test src\backend\AIMes.slnx

cd C:\AIWorks\AIMes\v1\src\frontend
npm run test:e2e -- dashboard.spec.ts scheduling.spec.ts audit.spec.ts report.spec.ts
```

Route: `/scheduling/scheduling`

What to show:

- Scheduler Pro Workbench hero.

## 3. Execution: Business Write

Recommended demo thread:

1. Show a Scheduling Agent decision.
2. Adopt or replay the already-recorded Agent execution.
3. Move to Audit for the write evidence.

What to show:

- Purchase receipt write: `PO-AGENT-001`.
- Quality disposition write: `insp-agent-1`.
- Equipment status write: `CNC-AGENT-01`.

Narration:

"This is the key upgrade: the Agent path is not just a front-end card. The system can show the action result, the business object, the trace ID, and the audit log that explains who did what and why."

## 4. Replay: Audit

Route: `/scheduling/audit-logs`

What to show:

- Evidence Replay Console.
- Business write replay cards.
- Decision detail with trace ID and action steps.
- Deep links into Purchase, Quality, and Equipment pages.

Narration:

"Audit replay is the proof layer. We can replay the chain from recommendation to action to business object. A reviewer can inspect the evidence without trusting the UI copy."

Evidence to mention:

- Audit e2e verifies Agent execute purchase, quality, and equipment replay.
- Replay links carry object focus parameters and land on the target module.
