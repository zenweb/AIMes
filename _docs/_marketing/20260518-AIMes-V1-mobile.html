OPTIMIZATION · 多目标

四个目标函数 ·
一个均衡模式

交期、利用率、换型、平衡四目标，可独立运行，可字典序组合，工厂可按场景切换。

DueDate

交期优先

最小化逾期时间加权和，适合订单交付压力大场景。

min Σ max(0, End−Due) · Weight
Utilization

利用率优先

最大化瓶颈设备繁忙占比，适合产能受限场景。

max Σ Busy / Total
Changeover

换型成本最小

最小化产品换型时间总和，适合多品种小批量。

min Σ Changeover(p → q)
Balanced 默认

均衡模式

字典序：先满足交期 ≥ 95%，再优化利用率，再压缩换型。

Lex: Due → Util → Co

QUICKSTART · 5 分钟启动

三步上车 ·
看到带数据的甘特

需要：Docker Desktop ≥ 4.20 · 8GB RAM · 20GB 磁盘空间。

1

克隆并启动

一条命令拉起 5 个容器（API · Postgres · Redis · RabbitMQ · Qdrant）。首次拉镜像约 3-5 分钟。

2

等待 healthy

看到所有容器 healthy 后，浏览器打开 http://localhost:5002，自动跳转到登录页。

3

登录 · 看到甘特

用 admin / admin@123 登录，立即看到带演示数据的排程甘特图。

~/aimes — bash
$ git clone https://github.com/YOUR_ORG/aimes.git $ cd aimes/v1 $ docker compose up -d   [+] Running 5/5 ✔ aimes-postgres Healthy ✔ aimes-redis Healthy ✔ aimes-rabbitmq Healthy ✔ aimes-qdrant Healthy ✔ aimes-api Healthy   Login → http://localhost:5002 Swagger → http://localhost:5002/swagger 默认账号 admin / admin@123
