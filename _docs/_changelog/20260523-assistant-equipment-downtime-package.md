# 2026-05-23 AI 助手设备停机复核包

## 背景

设备维护页面已经能把 `CNC-001` 停机事件同步到 `AI 排产` 和 OTD 证据链，但 `AI 生产助手` 对设备停机仍停留在解释和跳转层，不能直接生成可追溯的停机复核包。

## 变更

- `AI 生产助手` 新增 `生成设备停机复核包` 可执行动作。
- 动作生成 `CNC-001` 停机事件，复用 `aimes_equipment_downtime_event`，让 `AI 排产` 事件队列直接读取同一事实源。
- 动作同步写入 OTD `设备维护` 证据链：
  - 审计编号：`AUD-CHAT-EQ-DOWNTIME-CNC001-20260523-001`
  - 追踪编号：`TRACE-EQ-DOWNTIME-CNC-001`
  - 影响工单：`WO-2026-0042 / WO-RUSH-9001 / WO-DEMO-1001`
  - 维护窗口：`今日夜班 22:00-02:00`
- 聊天动作卡片拆出设备维护、AI 排产、风险预警和现场班组四类责任动作。
- 审计回放新增设备停机复核包专属文案，回放权限校验、替代设备、影响工单重排和瓶颈保护。
- 系统治理动作审计新增 `设备停机包` 标签。

## 验证

- 新增 E2E：`AI 生产助手 (ChatPanel) › 可执行动作：生成设备停机复核包并同步设备排产和审计`。
- 覆盖聊天生成、设备页跳转、排产事件队列、OTD 证据链和审计回放。
