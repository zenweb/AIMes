# 2026-05-21 P3 质量推荐实验扩大门禁审批

## 变更

- 新增 `Quality.RecommendationExperimentExpansionGate` 关键配置审批项，把质量推荐实验扩大门禁从静态风险阈值升级为可审批策略。
- 门禁默认待复核，审批通过后从 `采纳率 100% / 复验通过率 100% / 误召回 0 次` 调整为 `采纳率 100% / 复验通过率 >=95% / 误召回 0 次`。
- 质量灰度监控和 R3/R4/R5 实验对比读取同一门禁策略；R4 在审批通过后可判定 `门禁通过`，R5 仍因采纳与误召回不达标判定 `门禁未通过`。
- `系统管理 / Agent 治理` 展示质量实验扩大门禁、审批审计、每个实验版本的门禁判定，并允许通过/驳回该策略审批。
- `审计日志 / AI 决策回放` 增加质量实验门禁配置回放链，展示三项指标调整、审批责任人、审计编号和生效结论。
- `报表中心 / 质量推荐多版本实验对比` 与 CSV 导出同步展示扩大门禁、门禁判定和门禁审批审计。
