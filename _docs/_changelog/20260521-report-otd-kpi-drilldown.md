# 2026-05-21 报表中心 OTD KPI 多维钻取

## 背景

`报表中心` 已能展示 OTD 改善、证据链和经营钻取，但 `+14%` 仍是全局口径。管理者和售前 POC 需要继续回答：改善到底来自哪个客户、哪条产线、哪个产品族、哪个交付窗口，以及哪些延期仍不能算作厂内 Agent 恢复。

## 改动

- `OTD 改善复盘报告` 新增 `OTD KPI 多维钻取` 面板。
- 支持四类钻取维度：
  - `客户`：`华东新能源`、`出口备件客户`
  - `产线`：`CNC 精加工线`、`装配复检线`
  - `产品族`：`阀体组件`、`法兰盘 DN100`
  - `时间窗口`：`未来 24 小时`、`本周交付窗口`
- 每个钻取项展示基线 OTD、Agent OTD、提升、延期减少、恢复状态、主因、解释、下一步动作和追踪编号。
- CSV 导出新增 `OTD KPI多维钻取` 行，导出维度、对象、基线/Agent OTD、提升、延期减少、状态、主因、下一步动作和追踪号。
- 新增客户交付恢复承诺包：
  - 报表 KPI 钻取详情可点击 `生成客户交付恢复承诺包`。
  - 承诺包默认把 `华东新能源` 的基线 `76%`、Agent `94%`、提升 `+18%` 和延期减少 `3 单` 转成客户可复盘口径。
  - 承诺包写入 `aimes_otd_kpi_commitment_packages` 和统一 `OTD 复盘证据链` 的 `客户承诺包` 阶段。
  - `AI 生产助手` 可读取最新承诺包，回答客户交付恢复承诺口径、责任人、截止时间、责任动作和审计追踪。
  - `审计日志` 会把 `客户承诺包` 从普通 OTD 证据中区分出来，回放 KPI 钻取、客户承诺、责任动作和报表导出链路。
  - CSV 导出新增 `客户交付恢复承诺包` 行，带出承诺、负责人、截止时间、审计号和追踪号。
- 收紧 `report.spec.ts` 里与新增 KPI 文案冲突的定位器，避免同一文案在 KPI 卡片和详情区重复时触发 Playwright strict mode 误报。
