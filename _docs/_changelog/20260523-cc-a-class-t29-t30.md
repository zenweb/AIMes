### 关键设计选择 — 诚实优先

之前 PowerShell 硬编码的 +14% / p=0.031 看似漂亮，但客户问"重跑还是这个数吗 / 换种子还是这个数吗"无法回答。**v3.0 路线图原话："如果 ΔOTD 不显著，报告时明确标注'不显著'，不要吹嘘数字。"**

现在的真数字是 +10 pts 但 p=0.44 不显著（30 单样本量太小）—— 报告/JSON/Markdown **三处都明确标注 `significantAt95: false`**，这是诚实，不是缺陷。

- 或承认"30 单 demo 数据集就是说明产品形态用，真实显著证据要 POC 现场数据"，把销售故事讲法调整

## T-30 完成 — EF 迁移离线验证通过
