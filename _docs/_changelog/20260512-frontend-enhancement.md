# 甘特图前端可视化增强

## 演示数据扩展
- 5 设备: CNC-001(瓶颈), CNC-002, 注塑机, 装配线, 热处理炉
- 14 工单，跨设备依赖链（注塑→装配、CNC精加工→装配）
- 热处理炉上刻意放置了时间重叠的冲突任务

## 可视化增强
- 瓶颈设备（CNC-001，利用率85%）→ 红色 bar + 设备名标注 [瓶颈]
- 冲突任务（热处理炉两个 bar 重叠）→ 红色闪烁斜纹背景 + 发光阴影
- 常规排产任务 → 蓝色 bar
- tooltip 显示工单编号/设备/时间/换线信息

## 演示模式
后端不可用时自动展示丰富示例数据，完整展示甘特图交互能力
