# 2026-05-21 POC 首批真实工单试点运行闭环

## 背景

上一轮已经把 POC 复盘签署推进到上线交付行动包，但“现场运行”仍只是行动项。客户真正验收上线时，需要看到首批真实工单是否跑通排产采纳、生产执行、异常回写和审计复盘。本次把该行动项推进为可生成、可导出、可审计的试点运行确认。

## 变更

- 新增 `poc-pilot-run-sync.ts`，保存 `aimes_poc_pilot_run`，并写入统一 `OTD 复盘证据链` 的 `POC 试点运行` 阶段。
- `报表中心` 在 POC 上线交付包生成后新增 `确认试点运行闭环`：
  - 生成 `PILOT-WO-BATCH-20260521-001` 首批 30 单真实工单批次。
  - 固化 OTD 目标 `>= 96%`、实测 `97%`、样本工单、排产采纳原因和执行状态。
  - 固化 AI 排产、生产报工、治理审计三类检查点与追踪编号。
  - CSV 导出新增 `POC试点运行`、`POC试点工单`、`POC试点检查点` 行。
- `AI 生产助手` 可回答“POC 首批真实工单试点运行情况？”，输出批次、OTD、样本工单、检查点和审计追踪。
- `系统管理` Agent 治理新增 POC 试点运行治理卡，展示试点批次、OTD 实测和审计编号。
- `AI 排产` 事件队列新增 POC 试点运行复核事件，可生成“上线验收复核”建议。
- `生产报工` 未选中工单时也会显示全局执行追踪，使 POC 试点运行这种跨工单上线证据可以直接核对。
- `审计日志` 复用统一 OTD 证据链，自动回放 `TRACE-POC-PILOT-RUN-CLOSED-20260521`。
