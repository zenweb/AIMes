# 2026-05-19 功能深化脑暴清单

## 触发

用户要求“扫描所有的功能。每个功能都要做深点，开始头脑风暴”，在完成第一轮口头扫描后继续推进为可执行产品规划文档。

## 产出

新增 `_docs/_plan/20260519-function-deepening-brainstorm.md`。

## 内容

- 扫描当前 19 个前端导航入口与核心支撑能力。
- 将每个模块按“当前能力 / 深度评价 / 下一步定位”整理。
- 明确下一阶段不平均加厚所有模块，而是围绕“调度员 Agent + 排产优化 Skill + OTD 改善”形成业务闭环。
- 输出 P0/P1/P2/P3 深化方向：
  - P0：调度员 Agent 工作台
  - P1：风险预警行动队列、缺料齐套闭环、设备故障联动、生产执行闭环
  - P2：质量事件闭环、工程数据约束化、AI 生产助手动作化
  - P3：人员、条码、知识库、审计治理
- 给出 Sprint A-D 建议迭代顺序和售前 demo 路径。

## 关键决策

- 以 `ai-mes-roadmap.md` 中锁定的单点引爆路线为准。
- 短期不做多 Agent 平台、MCP Server、Skill Builder、插件市场、多租户 SaaS 后台和复杂低代码编排。
