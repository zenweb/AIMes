# 2026-05-19 POC 客户漏斗启动方案

## 触发
v3.0 路线锁定 C 单点引爆 + Demo + POC 双轨标杆数据策略后，按承诺起草 POC 客户漏斗具体方案，让 Phase C 不等 Phase A/B 完成就能并行启动。

## 产出
新建 `_docs/_plan/20260519-poc-customer-funnel.md`，包含：

1. **目标客户画像**：硬性条件 5 项（行业、生产模式、工单规模、数据基础、APS 现状）+ 软性偏好 + 反向画像（明确放弃哪类客户）
2. **价值主张话术**：一句话定位 + 5 个 FAQ 标准答案
3. **POC 提案模板**：8 周陪跑、退出条款、数据使用权交换条款
4. **外联渠道**：5 个渠道按 ROI 排序（个人人脉 → 行业社群 → 内容营销 → 行业会议 → 政府渠道）
5. **漏斗转化目标**：前 3 个月 100 触达 → 30 对话 → 10 评估 → 3 候选 → 1 成交
6. **关键风险**：4 类风险（拿了 demo 不付费 / OTD 不显著 / 单点说服力不够 / 销售挤占工程）+ 护栏
7. **本周立即可做清单**：5 个具体动作（人脉清单、私信、文章草稿、社群、时间窗口）
8. **POC 提案一页纸**：可直接发客户的版本

## 关键设计

- **漏斗转化数字是当前最佳猜测**，第 1 个月后根据真实信号迭代
- **POC 协议第一条就锁死案例发表权 + 反馈访谈**：即使不付费也能产出资产
- **第 W4 周双方互有终止权**：双方都不勉强
- **每周固定销售时间窗口**：避免销售挤占工程时间
- **5 个本周可做的具体动作**：把"启动 POC 漏斗"从口号变成 todo
