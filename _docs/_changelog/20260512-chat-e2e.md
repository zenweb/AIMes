# NL 聊天面板 + E2E 测试

## 新增功能

### Track 2: NL 自然语言查询 — 聊天面板
- **`frontend/src/components/chat/ChatPanel.vue`** — 右侧滑出聊天面板组件
  - 消息列表 + 输入框，支持 Enter 发送
  - API 调用（`POST /api/v1/knowledge/query`），后端不可用时自动降级为演示回复
  - 演示模式：支持产能/质量/工单/物料/设备等 6 类问题的智能回复
  - 参考来源折叠/展开显示（来源名称 + 相关度评分）
  - 对话历史加载（`GET /api/v1/knowledge/chat-history/{sessionId}`）
  - 打字动画 loading 效果
  - 滑入/滑出过渡动画
  - 空状态引导提示
  - 发送按钮在空输入时禁用
- **`frontend/src/types/knowledge.ts`** — 知识库 TypeScript 类型定义（KnowledgeQueryRequest/Response, ChatMessage, etc.）
- **`frontend/src/api/knowledge.ts`** — Axios API 封装（queryKnowledge, getChatHistory）
- **`frontend/src/components/layout/MainLayout.vue`** — 新增右下角浮动 AI 按钮（圆形蓝色 FAB）+ ChatPanel 集成

### Track 3: E2E 测试 — Playwright
- **`frontend/playwright.config.ts`** — Playwright 配置（Chromium, webServer 自动启动 Vite）
- **`frontend/tests/e2e/dashboard.spec.ts`** — 仪表盘 7 个测试：KPI 卡片、设备列表、(今日排产、物料预警、质量环形图、导航链接
- **`frontend/tests/e2e/scheduling.spec.ts`** — 甘特图 7 个测试：指标卡、工具栏、甘特图渲染、任务条数量、时间刻度切换、依赖箭头、瓶颈标记
- **`frontend/tests/e2e/chat.spec.ts`** — 聊天面板 7 个测试：浮动按钮、面板打开、发送消息、参考来源、关闭面板、空状态、禁用状态
- **`frontend/package.json`** — 新增 `test:e2e` 脚本

## 运行方式

```bash
cd frontend
npm run test:e2e              # 运行全部 E2E 测试
npx playwright test tests/e2e/dashboard.spec.ts  # 单独运行某文件
```
