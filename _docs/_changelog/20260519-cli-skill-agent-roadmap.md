## 核心洞察
1. V1 现有 REST API 是 CLI 化的良好基础，缺的是意图抽象和机器协议层
2. Skill 不是新模块，是对现有跨模块业务流程的纵向封装
3. Agent 不是万能 AI，是按岗位权限裁剪的有限智能副手
4. 三层架构叠加在现有业务模块之上，不需要推倒重建
5. **制造业 Agent 已有实证**：固纬电子 50% 缺陷率改善，AIMes 方向有量化业务价值锚点
6. **岗位 Agent 容量被低估**：百胜 Q睿 单 Agent 覆盖 20+ 场景，6 类 Agent 设计可更进取
7. **架构理念获权威验证**：Gartner AIR 框架（记录/行动/智能）与 CLI-Skill-Agent 同构，选型风险低
