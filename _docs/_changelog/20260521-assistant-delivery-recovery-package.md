# 2026-05-21 AI 生产助手交期恢复执行包

## 背景

`AI 生产助手` 已具备页面跳转、重排建议入口、报表导出和异常处置卡动作，但整体仍偏“单点动作”。现场调度更需要助手把一个高风险问题拆成跨模块责任动作，并能在排产、风险、报表和审计里追溯。

## 改动

- 新增 `assistant-action-package-sync.ts`，持久化 `WO-RUSH-9001 交期恢复执行包`，并同步写入统一 OTD 证据链。
- `ChatPanel` 新增 `生成交期恢复执行包` 动作：
  - 审计编号：`AUD-CHAT-RECOVERY-PACKAGE-20260521-001`
  - 追踪编号：`TRACE-CHAT-RECOVERY-WO-RUSH-9001-20260521`
  - 动作包卡片展示 `AI 排产 / 风险预警 / 采购协同 / 质量闭环` 四个责任动作。
- `AI 排产` 事件队列读取助手执行包，生成 `助手执行包` 事件，并可产出排产建议。
- `风险预警` 处置队列读取助手执行包，生成已升级的跨模块风险处置项。
- `报表中心` OTD 经营钻取识别 `助手执行包` 阶段，解释助手是否把问答转成可执行闭环。
- `审计日志` AI 决策回放对执行包动作展示跨模块拆解和 OTD 证据归档。
