# ProductionBoard 完工排产质量回写真实浏览器证据

日期：2026-06-07

## 目标

补齐生产执行中“完工报告、排产回写、质量联动、OTD 报表与审计回放”的真实 Chromium 证据：生产完工不能只更新本页状态，还必须进入排产复核、报表 OTD 证据链和审计决策链。

## 本轮变更

- 本轮未修改产品代码。
- 复跑既有 e2e：`完工后生成排产与质量回写记录`。
- 使用 Nuxt production build + Playwright Chromium 项目验证真实浏览器链路。

## 真实浏览器证据

命令：

```powershell
npm.cmd run test:e2e -- tests/e2e/production.spec.ts -g "完工后生成排产与质量回写记录"
```

结果：

```text
Running 1 test using 1 worker
ok 1 [chromium] › tests\e2e\production.spec.ts:396:3 › Production 生产看板 › 完工后生成排产与质量回写记录 (2.7s)
1 passed (5.1s)
```

验证点：

- 生产页工单卡可打开详情并触发 `完工报告`。
- 完工确认后，执行追踪面板出现 `排产回写`。
- 执行追踪说明 `完工进度已回写`，并展示工单进度更新。
- 执行追踪出现 `生产复核`，并说明 `完工复核已提交`。
- 执行追踪出现 `质量联动`，并说明 `质检放行`。
- 排产页事件队列出现 `WO-001 CNC 精加工 完工复核`。
- 排产事件展示 `生产完工事件`，状态为 `已复核` 或 `待复核`。
- 点击事件动作后展示 `生产完工复核建议`。
- 排产建议说明需复核后续工序窗口、质量门和 OTD 证据链。
- 报表页 OTD evidence chain 出现 `完工回写`，并展示 `生产完工` 与 `TRACE-PROD-COMPLETE`。
- 审计页指标展示 `生产完工回放 1` 和 `生产复核回放 1`。
- 审计页存在 `生产复核：WO-001 CNC 精加工 完工复核` 决策卡。
- 决策卡展示 `生产复核证据` 与 `证据：TRACE-PROD-CLOSEOUT-OP-20`。
- 审计详情回放生产报工、排产页复核、质量门和承诺交期。
- 审计详情展示当前状态为 `完工复核已提交` 或 `OTD 风险待复核`。
