# MonitoringBoard 现场态势处置包闭环真实浏览器证据

日期：2026-06-07

## 目标

补齐实时监控中“现场态势升级、风险关闭、排产复核、审计闭环”的真实 Chromium 证据：现场事件升级为跨模块处置包后，必须能在风险队列关闭，并反写排产复核与审计回放状态。

## 本轮变更

- 本轮未修改产品代码。
- 复跑既有 e2e：`现场态势处置包关闭后反写排产复核和审计闭环状态`。
- 使用 Nuxt production build + Playwright Chromium 项目验证真实浏览器链路。

## 真实浏览器证据

命令：

```powershell
npm.cmd run test:e2e -- tests/e2e/monitoring.spec.ts -g "现场态势处置包关闭后反写排产复核"
```

结果：

```text
Running 1 test using 1 worker
ok 1 [chromium] › tests\e2e\monitoring.spec.ts:89:3 › Monitoring 现场态势图 › 现场态势处置包关闭后反写排产复核和审计闭环状态 (2.4s)
1 passed (5.1s)
```

验证点：

- 监控页 `.shopfloor-situation` 可点击 `升级为跨模块处置包`。
- 页面展示 `现场态势已升级为跨模块处置包`。
- 风险页 `.risk-action-panel` 出现 `CNC-001 现场态势升级处置包`。
- 风险卡点击 `关闭` 后状态显示 `已关闭`。
- 风险卡展示 `已反写现场处置包`。
- 风险队列 trace 显示状态已更新为 `已闭环`。
- 排产页事件队列出现 `CNC-001 现场态势升级处置包`。
- 排产事件显示 `已缓解` 和 `风险关闭后复核`。
- 点击 `复核排产影响` 后展示 `CNC-001 现场态势升级处置包闭环复核建议`。
- 排产复核建议说明该处置包 `已由风险队列关闭`。
- 审计页现场处置包卡片显示 `已闭环`。
- 审计回放详情包含 `关闭留痕：CNC-001 现场态势升级处置包 已关闭`。
- 审计回放详情包含 `当前状态为 已闭环`。
