# 缺料齐套闭环 (P1)

## 概述

把库存模块、BOM 展开、在途量和排产时间窗合并成缺料决策视图，形成"检查 → 预测 → 处置 → 闭合"闭环。

## 实现范围

### 工单齐套检查
- 按工单展示需要量、可用量、在途量、缺口
- 覆盖 WO-RUSH-9001（M-AL-6061 缺口 19 件）、WO-DEMO-1002（MAT-B02 在途不足）
- 按排产窗口预测：今天缺 / 3 天后缺 / 7 天内齐套
- 自动建议：调拨、替代料、采购加急、调整排产顺序

### 采购收货闭合
- 采购协同完场加急收货后，OTD 证据链从"待齐套"更新为"采购收货已齐套"
- Agent 治理缺料待办同步更新（1 待处理 → 0 待处理）

### AI 集成
- AI 排产事件队列读取齐套缺口生成缺料事件
- AI 生产助手可解释"WO-RUSH-9001 为什么延期"，展示齐套/已齐套状态
- 助手可执行：生成 BOM 展开齐套检查包
- 助手风险排行：采购收货后工单从高风险降级为观察项
