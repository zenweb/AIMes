# 生产执行闭环 (P1)

## 概述

把生产报工从操作按钮扩展为现场约束卡，开工/完工与排产、质量、设备、人员联动。

## 实现范围

### 工序约束卡
- 展示 SOP、质检点、设备要求、物料齐套状态
- 开工校验：人员资质、设备状态、物料齐套、上道工序、SOP 版本、质检点
- demo 约束：CNC 精加工 SOP V2.3、首件尺寸复检、CNC-002、AL-6061 齐套

### 完工回写
- 更新排产进度、触发质检、更新 OTD 统计
- 完工写入 OTD 证据链（生产完工 / 生产复核）
- AI 排产事件队列新增 production 事件类型

### 异常上报
- 异常上报生成生产异常共享事件
- 异常管理置顶显示 + AI 处置建议
- 风险预警自动转成风险处置卡
- Agent 治理：生产执行治理区块（扫码执行/开工/完工/物料消耗/质量门）

### AI 集成
- AI 生产助手可解释完工后 OTD 复核影响
- 助手可执行：生成异常处置包联动风险/排产/审计
