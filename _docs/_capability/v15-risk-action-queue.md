# 风险预警 → 行动队列 (P1)

## 概述

将静态风险卡片升级为可执行工作项，每个风险生成处置卡。

## 实现范围

### 风险处置队列
- 处置卡：风险类型、影响工单、交期影响、建议动作、负责人、截止时间、状态
- demo 覆盖：CNC 停机延期、AL-6061 齐套缺口、CNC-001 主轴振动异常
- 支持转派、升级、关闭，操作后更新负责人、状态和处置留痕

### SLA 晨会复核
- 风险 SLA 逾期晨会复核包（RISK-DAILY-编号）
- 聚合未关闭风险为生产经理晨会复核项
- 闭环后 OTD 证据链从 active → closed，AI 排产事件切换为"已缓解"
- 晨会包可专属审计回放（风险 SLA 证据）

### AI 集成
- AI 排产事件队列读取风险状态生成排产保护建议
- AI 生产助手可回答"风险 SLA 晨会复核情况"
- Agent 治理：风险 SLA 晨会治理卡
