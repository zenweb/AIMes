# AI 生产助手 → 可执行助手 (P2)

## 概述

将 AI 生产助手从纯文本 RAG 问答升级为可执行业务动作入口，识别意图、执行动作、留痕审计。

## 实现范围

### 业务问答
- "为什么这个订单延期？" → 缺料、瓶颈设备、质量返工 + 恢复路径
- "今天最危险的 3 个工单？" → 风险排序依据
- "如果 CNC-001 故障 4 小时？" → 影响工单、替代设备、重排建议
- 接入 RAG 引用治理，展示引用来源/阻断来源

### 可执行动作
- 打开页面：AI 排产、风险预警、报表中心、BOM 管理、设备维护等
- 生成重排建议入口
- 导出 OTD 复盘报告（CSV）
- 创建异常处置卡（权限校验 + 审计编号）
- 生成交期恢复执行包（跨模块：排产/风险/采购/质量）
- 生成设备停机复核包
- 生成 BOM 展开齐套检查包
- 生成异常处置包
- 生成客户交付恢复承诺包
- 生成工程约束复核包

### 执行包闭环
- 交期恢复执行包：AI 排产、风险预警、采购、质量四类责任动作
- 排产侧交接闭环、采购责任回写、质量首件复核
- Agent 治理：交期恢复执行包治理区块

### 权限与审计
- 每次动作带角色校验（Admin / Engineer）
- 写入审计编号和追踪编号
- 审计日志 AI 决策回放区分普通动作和执行包动作
