# 知识治理与 RAG 引用链 (P3)

## 概述

将文档上传升级为 RAG 数据治理中心，管理知识来源的索引状态、有效期、引用追踪和过期风险。

## 实现范围

### 知识资产治理
- 文档分类、版本、索引状态、有效期、引用模块
- demo 数据：CNC 精加工 SOP V2.3（已索引）、装配扭矩规范 V1.8（即将过期）、CNC-01 主轴维护手册 V1.1（待索引/已过期）
- 过期待索引文档可复核并重建索引 → 升级版本、延长有效期

### AI 助手引用链
- 展示业务问答命中的引用文档、可引用/需复核状态
- 过期/待索引来源作为"阻断来源"展示
- 复核后阻断来源升级为可正式引用

### Agent 治理联动
- Agent 治理顶部指标：知识待治理
- 知识来源治理区：待治理/已复核卡片
- 待治理卡可直接跳转到文档治理页执行复核
