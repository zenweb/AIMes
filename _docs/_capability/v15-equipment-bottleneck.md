# 设备故障与瓶颈联动 (P1)

## 概述

将设备状态变化自动转换为排产影响，使设备维护与排产工作台联动。

## 实现范围

### 故障影响分析
- CNC-001 不可用影响排产：预计停机 4h、影响 3 工单
- 可替代设备：CNC-002 / CNC-003
- 推荐维护窗口：今日夜班 22:00-02:00
- 瓶颈保护策略：减少换线、优先关键订单、推荐预防维护

### Agent 集成
- 设备页标记故障后写入前端共享事件
- AI 排产事件队列新增 CNC-001 停机事件
- Agent 建议覆盖：换设备、延后、加班、拆单
- 审计回放：设备停机证据专属回放
- AI 生产助手可解释 CNC-001 故障 4 小时影响
- 助手可执行：生成设备停机复核包
