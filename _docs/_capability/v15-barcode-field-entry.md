# 条码现场入口 (P3)

## 概述

把条码从工具型功能升级为现场入口，覆盖扫码 → 开工 → 完工 → 质量门 → 复验放行的全链路。

## 实现范围

### 扫码上下文跳转
- 扫工单（WO-*）→ 生产报工 + 排产影响
- 扫设备（CNC-01/EQ-*/HT-*/ASM-*）→ 设备详情 + 实时监控
- 扫物料（M-*）→ 库存齐套 + BOM 用量

### 扫码执行证据
- 扫码确认 → `扫码执行` 阶段 OTD 证据
- 扫码流入生产报工 → 流转卡上下文 → 开工确认 → `生产开工` 证据
- 扫码完工报数 → `扫码完工` + `物料消耗` 证据
- 扫码异常上报 → `扫码异常` 证据

### 质量门与复验
- 质检不合格 → `扫码返工` + `交接冻结` + `质量CAPA` + `标签状态`
- 复验放行 → `质量复验` + `交接释放` + `排产回写` + `标签解冻`
- 质量隔离 + 返工成本预估
- 排产事件队列读取扫码返工释放 → 生成 OP-20 窗口恢复事件

### 追溯标签打印
- 工单/设备/物料标签批次，打印前展示扫码后业务去向
- 标签冻结/解冻状态联动
