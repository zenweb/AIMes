# 异常管理 → 现场事件中心 (P2)

## 概述

把异常从列表记录升级为跨模块事件分流入口，覆盖设备、质量、物料三类异常。

## 实现范围

### 三类事件分流
- 设备事件（CNC-001 主轴温升）→ 风险队列 + AI 排产 + 设备维护
- 质量事件（装配间隙超差）→ 质量闭环 + 返工/复验窗口 + OTD 复盘
- 物料事件（原料批次来料异常）→ 库存齐套 + 采购协同 + 风险下降

### 可确认分流
- 确认分流后写入 `aimes_anomaly_dispatch_records`
- 风险预警行动队列读取分流记录
- AI 排产事件队列生成异常分流事件
- 报表 + 审计通过 OTD 证据链追溯

### AI 集成
- AI 生产助手可解释异常分流后的现场事件处置影响
- Agent 治理：异常分流治理区块，按类型提供跳转入口
- 审计回放：异常分流证据专属回放
