# 质量事件闭环与知识 R3-R7 链 (P2/P3)

## 概述

从检验不合格自动生成质量事件 → 返工影响排产 → CAPA 处置 → 扫码质量门 → 质量知识沉淀 → R3-R7 灰度发布/回滚/实验对比的完整链路。

## 实现范围

### 质量返工与排产联动
- 检验不合格自动生成返工排产事件
- AI 排产 Agent 建议：插入返工与复验窗口、合并同工艺批次
- CAPA 闭环：根因证据强度、纠正/预防措施、验证结果

### 扫码质量门
- 扫码完工质检不合格 → 返工冻结 → 交接冻结 → CAPA → 标签冻结
- 复验放行 → 交接释放 → 排产回写 → 标签解冻
- 质量隔离 + 返工成本预估证据

### 质量知识 R3-R7 全链路
- 扫码返工样本 → CAPA 知识复用 → 同类缺陷命中 → 处置草案 → 正式 CAPA → 效果回写
- 低分复核 → 直接复用禁用 → 再训练候选 → R3 审批/校验/灰度发布
- R3 灰度监控 → 扩大/回滚决策 → 审批链 → 问题单处置
- R3 重新灰度发布 → R4 扩大 → R5 回滚 → R6 补样 → R7 影子验证
- 多版本实验对比 + Agent 治理实验池

### 关键特性
- 统一 localStorage `aimes_quality_knowledge_*` 系列 28+ 同步层
- 审计回放 10+ 专属卡片（质量复验、质量灰度、质量推荐等）
- Agent 治理 8+ 区块（知识策略、实验池、灰度监控等）
