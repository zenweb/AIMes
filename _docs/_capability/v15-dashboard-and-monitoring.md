## 实时监控 → 现场态势图

将设备/物料/质量事件转成现场事件流：
- CNC-001 瓶颈负载 90%、M-AL-6061 齐套缺口、INS-003 返工占用窗口
- 每条事件展示来源、影响工单、负责人、动作入口
- 现场态势升级处置包 → 跨模块联动（风险预警、AI 排产）
- 处置包闭环反写：风险关闭 → OTD 证据链 closed → 排产复核
