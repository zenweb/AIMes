# 人员能力约束 (P3)

## 概述

将人员管理从基础后台能力升级为排产约束来源，覆盖技能、资质、替班、阻断和开工校验。

## 实现范围

### 技能矩阵与资质
- demo 人员数据：EMP-001（CNC 精加工 2 级）、EMP-003（热处理上岗证/临期）
- 班组、班次、资质有效期可视化

### 替班候选与评分
- 按技能匹配、证书有效、班组、班次、排班可用性、班组长授权排序
- EMP-009 请假（capacityHours=0）不进入候选
- 替班建议 → 班组长复核 → 工程放行 → OTD 证据链

### 停工复核状态机
- 无有效候选 → 人员阻断（workers blocked）+ 停工复核
- 主管受理 → reviewing + 人员复核证据
- 补证改派 → released + 人员放行证据
- 生产报工开工校验：阻断 → 确认按钮禁用；放行 → 恢复开工

### AI 集成
- AI 排产人员能力约束解释
- 人员替班事件 / 人员资质阻断事件
- Agent 治理：人员能力治理区块
- AI 生产助手可解释替班对开工和排产的影响
