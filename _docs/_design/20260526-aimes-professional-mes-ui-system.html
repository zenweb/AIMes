1. 设计定位

本轮采用“专业制造运营控制塔”方向，一屏优先呈现工厂、产线、班次、审计和动作落库状态。

信息密度高支持现场高频扫描，但保持清楚层级。
避免营销化不使用大面积装饰 hero 或空泛宣传结构。
现场对象优先工厂、产线、工单、风险、审计是一屏首要信号。
状态色明确蓝色计划、绿色闭环、琥珀预警、红色阻断。

3. 组件规范

App Shell左侧 288px 专业导航，包含工厂上下文、模块分组、AI Agent Control 状态。
Topbar / Ribbon显示搜索、模块、连接、班次、证据链，以及现场节拍、OTD、风险队列、动作落库。
Cards / Panels统一 8px 半径；页面 section 全宽或网格；避免卡片套卡片。
Tables / Dense Data弱背景表头、12px 次级文字、紧凑行内操作，服务扫描和比较。
