# 2026-06-14 Issue - 多目标对比缺少推荐方案

## 问题
- `ParetoCompare.vue` 旧逻辑允许 `optimize-compare` 返回非空 `items` 但没有 `bestOverallObjective`。
- 页面会继续展示对比表、甘特图和每行“采用”按钮。
- 这会让推荐型流程变成没有后端推荐依据的手动采纳，削弱排产推荐的可解释性和可追溯性。

## 影响
- 用户关键路径：排产看板的多目标方案对比和推荐方案采用。
- 风险类型：缺少推荐依据、采用动作与后端对比结论脱节、后续审计难以解释“为什么采用此方案”。
- 严重性：中，属于现有排产功能必须补齐的可靠性和可审计性缺口。

## 修复
- 当 `bestOverallObjective` 省略或空白时抛出 `后端对比结果缺少推荐方案`。
- catch 分支沿用现有 fail-loud 告警，清空对比项、推荐目标和当前 tab。
- 单测和 Chromium e2e 均断言不展示推荐卡或“采用此方案”入口。

## 验证
- 单测覆盖缺少推荐方案必须 fail-loud。
- Chromium 真实浏览器覆盖缺少推荐方案后弹窗展示失败告警。
- 完整排产 Chromium 套件和前端覆盖率总检均通过。
