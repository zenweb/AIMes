# 20260619 Anomaly Dispatch Guidance Links Issue

## 问题
异常管理的现场事件中心允许用户点击“确认分流”，该操作会写入下游异常分流证据。但操作区此前缺少明确的中英双语核对提示、帮助入口和模块关联链接。

## 影响
- 用户在确认分流前不容易确认异常类型、影响工单、目标模块、责任人和审计追踪是否完整。
- 风险、质量、排产等相关处置入口需要用户自行寻找。
- 复杂操作缺少可点击帮助支持，不符合当前核心产品原则。

## 处理
- 新增 `#anomaly-dispatch-help` 引导区。
- 增加风险预警、质量闭环、AI 排产、帮助四个关联入口。
- 将 `.event-lanes` 通过 `aria-describedby` 关联到帮助提示。

## 状态
- 已修复并完成单测、全量覆盖率、lint、build、真实浏览器验证。
