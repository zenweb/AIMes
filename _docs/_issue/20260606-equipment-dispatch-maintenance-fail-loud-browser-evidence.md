# Issue: EquipmentScheduleImpactPanel 异常分流维护复核单失败误报成功

日期：2026-06-06

## 问题

`生成维护复核单` 会把异常分流设备维护记录写入设备停机事件和 OTD 证据链。OTD 证据链写入失败时，页面需要把维护/OTD 证据未完整归档暴露给用户，不能让用户误以为维护复核单已经完整同步。

## 影响

- 用户可能认为异常分流维护复核单已经进入 OTD 审计链。
- 发布审计可能误把缺失证据当作已归档维护复核单，违反 fail-loud 约定。

## 修复

- `syncDispatchMaintenance()` 捕获维护复核单写入异常。
- 失败时切换 `role="alert"`，显示 `异常分流维护单同步失败` 与具体错误原因。
- 新增单测和真实 Chromium e2e 证据。

## 状态

- 已修复并验证目标用例。
- 发布 B 轨道闸门仍未关闭。
