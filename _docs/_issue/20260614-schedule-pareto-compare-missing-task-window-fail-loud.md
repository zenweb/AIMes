# 2026-06-14 Issue - 多目标对比计划项缺少时间窗

## 问题
- `ParetoCompare.vue` 旧逻辑只要求对比项有 `plan.items`，不检查每个计划项是否具备开始和结束时间。
- 当后端返回的计划项缺少 `plannedStartTime` 或 `plannedEndTime` 时，页面仍会展示推荐卡、KPI 表和“采用”按钮。
- 这会让缺少任务级时间窗口的方案进入采用路径，后续甘特图和回写链路缺少可执行依据。

## 影响
- 用户关键路径：排产看板的多目标方案对比和推荐方案采用。
- 风险类型：假可落地方案、任务无法定位到甘特图时间轴、采用后反馈链缺少排产窗口依据。
- 严重性：中高，属于现有排产功能必须补齐的可靠性和可审计性缺口。

## 修复
- 当任一 `item.plan.items` 计划项缺少 `plannedStartTime` 或 `plannedEndTime` 时抛出 `后端对比方案计划项缺少时间窗`。
- catch 分支沿用现有 fail-loud 告警，清空对比项、推荐目标和当前 tab。
- 单测和 Chromium e2e 均断言不展示推荐卡或“采用此方案”按钮。

## 验证
- 单测覆盖“计划项缺少时间窗”必须 fail-loud。
- Chromium 真实浏览器覆盖该缺陷载荷后展示失败告警。
- 完整排产 Chromium 套件和前端覆盖率总检均通过。
