# 2026-06-14 Issue - 多目标推荐公式说明不可审计

## 问题
- 排产多目标对比已有推荐分与三项贡献，但公式版本、权重和换线归一化口径未作为 API 契约返回。
- 前端推荐卡只能展示贡献值，用户无法直接确认 `40/40/20` 和 `1000 分钟归一化` 的计算口径。

## 影响
- 推荐理由可读但不够可审计。
- 如果后端公式变化而前端说明未同步，真实浏览器路径无法及时暴露口径漂移。

## 处理
- 后端新增 `RecommendationScoreFormula` 顶层元数据。
- 前端推荐卡展示公式版本、权重和归一化口径。
- 增加后端单元、后端集成、前端单测与真实 Chromium 断言。

## 状态
- 已关闭。
- 灰度 15 天观察按负责人指示跳过，不作为该 issue 阻塞项。
