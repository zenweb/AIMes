# Issue: EquipmentScheduleImpactPanel 客户设备故障样例失败误报成功

日期：2026-06-06

## 问题

`生成客户设备故障样例` 会先写入设备停机事件，再写入客户样例 OTD 证据。第二次 OTD 证据链写入失败时，页面需要把 POC/OTD 证据未完整归档暴露给用户，不能让用户误以为客户样例已经完整接入。

## 影响

- 用户可能认为客户真实设备故障样例已经进入 OTD 风险口径。
- 发布审计可能误把缺失证据当作已归档样例，违反 fail-loud 约定。

## 修复

- `prepareCustomerFaultEvidence()` 捕获客户样例 OTD 写入异常。
- 失败时切换 `role="alert"`，显示 `客户设备故障样例同步失败` 与具体错误原因。
- 新增单测和真实 Chromium e2e 证据。

## 状态

- 已修复并验证。
- 发布 B 轨道闸门仍未关闭。
