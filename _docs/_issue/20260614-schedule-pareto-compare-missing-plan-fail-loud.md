# 2026-06-14 Issue - 多目标对比项缺少排产计划

## 问题
- `ParetoCompare.vue` 旧逻辑信任每个对比项都有 `plan`。
- 当后端返回完整指标和推荐目标，但单个 `items[]` 缺少 `plan` 时，页面仍会展示推荐卡、雷达图和“采用”按钮。
- 这会让只有 KPI 摘要、没有可落地排产计划的方案进入采用路径。

## 影响
- 用户关键路径：排产看板的多目标方案对比和推荐方案采用。
- 风险类型：假可落地方案、甘特图数据不可追溯、采用后反馈链缺少计划依据。
- 严重性：中高，属于现有排产功能必须补齐的可靠性和可审计性缺口。

## 修复
- 当任一 `item.plan` 缺失或 `item.plan.items` 不是数组时抛出 `后端对比方案缺少排产计划`。
- catch 分支沿用现有 fail-loud 告警，清空对比项、推荐目标和当前 tab。
- 单测和 Chromium e2e 均断言不展示推荐卡或“采用此方案”按钮。

## 验证
- 单测覆盖单个对比项缺 `plan` 必须 fail-loud。
- Chromium 真实浏览器覆盖缺 `plan` 后弹窗展示失败告警。
- 完整排产 Chromium 套件和前端覆盖率总检均通过。
