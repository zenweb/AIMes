# Issue: QualityCapaTaskPanel 低分复核队列生成失败伪造风险

## 背景

低分样本复核队列用于阻断跨工序、跨设备、缺陷模式不一致的质量知识推荐直接进入 AI 助手引用。如果复核队列写入失败但页面继续显示成功，用户会误以为低分样本已进入人工复核和后续负样本治理。

## 处理

- 新增真实 Chromium 用例覆盖 `aimes_quality_knowledge_review_queue` 写入失败。
- 验证页面显示 `低分样本复核队列生成失败`。
- 验证失败后保留生成按钮，不显示低分复核 trace，不写入复核队列记录或 OTD 证据。

## 当前状态

目标真实浏览器用例已通过。
