# 2026-06-14 Issue - 批量对比采纳未进入最近反馈

## 问题
- 批量对比方案采纳后，toolbar 和 warning 会显示新方案已应用。
- 但“最近反馈”仍显示 `等待调度员决策`，用户无法在复盘区看到这次采纳动作。

## 影响
- 采纳状态分散在 toolbar / warnings / sync-note，复盘区缺少同一动作记录。
- 当后台反馈同步失败时，用户虽然能看到失败原因，但最近反馈没有本地采纳记录，状态可信度不足。

## 修复
- 批量对比方案成功采纳后写入 `latestFeedback`。
- 记录内容包含决策、类别、目标名称和采纳说明。
- 单测与真实 Chromium 均覆盖该记录。

## 剩余风险
- 页面最近反馈已经修复，但刷新后的本地持久化仍需单独切片验证。
