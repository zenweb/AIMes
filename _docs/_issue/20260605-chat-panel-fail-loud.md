- 风险：用户可能重复导出报表，审计也会把已完成导出记录为 `permitted: false`，与真实业务状态不一致。
- 处理：在 CSV 导出分支内捕获报表中心跳转失败，保留完成状态和成功审计，只额外显示跳转失败 alert。
- 问题：`ChatPanel.vue` 的 OTD/POC 复盘 CSV 已触发下载后，下载链接清理失败会触发外层失败路径，误报“动作执行失败”。
- 风险：用户可能重复导出报表，审计也会把已完成导出记录为 `permitted: false`；清理失败原因也没有独立暴露。
- 处理：在 CSV 导出函数内捕获 `URL.revokeObjectURL()` 失败，保留完成状态和成功审计，只额外显示下载链接清理失败 alert。
- 问题：`ChatPanel.vue` mounted 阶段同步 backend-first 上下文失败时会产生 Vue unhandled error，没有明确告知用户助手上下文未完成同步。
- 风险：用户可能在异常调度、现场态势或风险 SLA 上下文缺失时继续问答，误判助手回答的证据新鲜度。
- 处理：捕获启动上下文同步异常，保留聊天入口，并用 assertive alert 展示“助手上下文同步失败”和失败原因。
- 问题：`ChatPanel.vue` 的 OTD/POC 复盘 CSV 在 Blob URL 创建失败时只显示通用“动作执行失败”，没有明确告知用户下载准备失败。
- 风险：导出尚未完成，但用户可能无法区分下载准备失败、后续跳转失败和已导出后的清理失败，导致重复操作或误判报表证据状态。
- 处理：`export_report` 未完成导出前失败时显示“OTD/POC 复盘 CSV 下载准备失败”和失败原因，保持失败审计，不显示完成状态、不跳转报表中心。
- 问题：`ChatPanel.vue` 的 OTD/POC 复盘 CSV 已创建 Blob URL 后，如果 `a.click()` 下载点击失败，已创建的 object URL 不会释放。
- 风险：导出失败路径会泄漏浏览器 Blob URL；用户虽然看到失败提示，但多次失败导出会累积资源占用。
- 处理：下载点击失败时先尝试 `URL.revokeObjectURL(url)`，再保留原始点击失败作为“下载准备失败”的用户可见原因。
- 问题：`ChatPanel.vue` 重新打开时如果 `getChatHistory()` 失败，会静默显示空状态，没有告知用户历史加载失败。
- 风险：用户可能误判历史会话为空，并在缺失上下文的状态下继续问答。
- 处理：历史加载失败时显示 assertive alert，包含“聊天历史加载失败”和失败原因，同时保留聊天入口可继续使用。
- 问题：`ChatPanel.vue` mounted 阶段如果 `getLlmStatus()` 失败，会静默隐藏模型徽标，没有告知用户 LLM 状态不可观测。
- 风险：用户可能误判模型状态正常，继续使用 AI 助手但不知道当前模型状态接口失败。
- 处理：LLM 状态加载失败时显示 assertive alert，包含“LLM 状态加载失败”和失败原因，同时保留聊天入口可继续使用。
- 问题：`ChatPanel.vue` 启动上下文同步使用单个 `try` 包裹三个 backend-first 来源，首个来源失败会阻止后续来源加载。
- 风险：异常调度来源失败时，现场态势和风险 SLA 上下文不会被尝试读取，AI 助手在缺少可用证据的情况下继续回答。
- 处理：启动上下文同步改为来源级 fail-loud，每个来源失败只降级自身，其它来源继续读取。
