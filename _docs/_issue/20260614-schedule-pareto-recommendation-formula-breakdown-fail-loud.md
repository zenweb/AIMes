# 2026-06-14 Issue - 推荐分数组成未校验公式来源

## 问题
- 前端已有推荐分与三项贡献求和一致性校验，但未验证三项贡献是否按后端公式由 KPI 计算得出。
- 后端可能返回总分自洽的贡献值，却与 `40/40/20` 和换线归一公式不一致。

## 影响
- 推荐卡可能展示“可审计”的贡献值，但贡献来源实际已经漂移。
- 用户采纳推荐方案时，无法从 UI 发现公式与贡献口径不一致。

## 处理
- 新增公式一致性校验。
- 异常时显示 `后端推荐分数组成与公式不一致`。
- 增加单测红绿证据与真实 Chromium 回归证据。

## 状态
- 已关闭。
- 灰度 15 天观察按负责人指示跳过，不作为该 issue 阻塞项。
