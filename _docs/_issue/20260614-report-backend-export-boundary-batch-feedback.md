# 2026-06-14 Issue - Excel/PDF 导出边界可能误导批量采纳证据覆盖

## 问题
- 批量对比采纳 snapshot 已进入报表页面、钻取详情和 CSV 导出。
- Excel/PDF 按后端 `/api/v1/report/export/*` 快照生成，不会读取前端 localStorage 的本地批量采纳证据。
- 原界面没有说明该边界，用户可能误以为所有导出格式都包含同一份本地证据链。

## 影响
- 审计或客户复盘时可能拿 Excel/PDF 查找批量采纳 traceId，得到空结果后误判为证据链丢失。
- 后续开发也可能在未读后端导出实现的情况下重复排查。

## 修复
- 在导出按钮区展示 `本地采纳证据随 CSV 导出；Excel/PDF 为后端报表快照。`
- Excel/PDF 成功发起下载后展示 `本地批量采纳证据请使用 CSV 导出。`
- 单测覆盖 Excel/PDF 成功提示，Chromium 用例覆盖批量采纳 snapshot 下的 CSV 证据和 Excel 边界提示。

## 剩余风险
- 如果产品要求 Excel/PDF 也包含本地采纳证据，需要后续做统一报表快照输入设计。
