# 2026-06-06 EmployeeBoard 员工弹窗语义 Issue

## 已处理

- 员工编辑/详情弹窗原本没有 modal dialog 语义，屏幕阅读器无法通过角色和标题稳定识别。
- 新增员工弹窗原本也缺少同样语义。
- 关闭/取消按钮缺少场景化可访问名称。
- 编辑弹窗原本不会在打开后接收焦点，键盘用户按 Escape 不能关闭弹窗；关闭后也没有焦点回收证据。

## 新发现但未处理

- 无。

## 追加处理

- 真实 Chromium 鼠标路径中，`.skill-matrix-panel` / `.emp-board` 曾拦截员工卡片点击。
- 根因：技能矩阵内容高度超过视口后，员工列表被压到视口外且列表高度为 0，页面滚动容器不正确。
- 修复：`EmployeeBoard` 改为页面级纵向滚动，员工列表恢复内容高度。
- 修复：编辑/详情弹窗打开后聚焦到 dialog；Escape 关闭后回焦到原员工卡片。
- 修复：新增员工弹窗打开后聚焦到 dialog；Escape 关闭后回焦到 `+ 新增` 按钮。
