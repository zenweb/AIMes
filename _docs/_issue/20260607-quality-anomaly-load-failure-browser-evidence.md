# 2026-06-07 Issue - 质量异常告警加载失败 Chromium 证据

## 问题

质量异常告警加载失败已有单元测试覆盖，但缺少真实 Chromium 证据证明浏览器中 `/api/v1/anomaly` 失败时不会把告警区渲染为空状态。

## 影响

如果该路径失败时静默或显示 `暂无异常告警`，用户会误判当前没有质量异常，影响 MRB、返工和排产处置判断。

## 处理

- 新增 e2e 关闭 offline demo，mock 无关质量 API 成功。
- 注入 `/api/v1/anomaly` 503。
- 断言 alert 明确展示 `质量异常告警加载失败`。
- 断言 fallback 异常告警仍展示 3 条，且不显示空状态。

## 状态

A 轨此切片已用 Chromium 定向验证通过。B 轨发布闸门仍未关闭。
