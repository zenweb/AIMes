# 2026-06-14 Issue - 批量方案采纳提示竞态

## 问题
- 批量方案采纳后，用户应看到 `综合平衡方案已应用`。
- 当初始排产加载较晚失败时，旧逻辑会把 `.warnings-bar` 覆盖为 `后端排产服务不可用...`。
- 真实 Chromium 全套曾因此出现首次失败、retry 后通过的 flaky。

## 影响
- 用户采纳后的本地目标切换已经生效，但页面主提示可能显示旧加载失败原因，削弱采纳状态可信度。
- 完整浏览器证据依赖 retry，不符合精品级现有功能要求。

## 修复
- 引入 `scheduleStateVersion` 作为排产状态写入护栏。
- 初始加载结果只在版本未变化时写入。
- 优化采纳成功后递增版本，使旧加载请求失效。

## 剩余风险
- 该版本护栏只保护当前组件内的排产状态写入；跨模块后台同步状态仍依赖各自的 fail-loud 文案和测试覆盖。
