# 2026-06-07 Issue - 质量知识样本写入失败 Chromium 证据

## 问题

质量知识样本写入失败已有单元测试覆盖，但缺少真实 Chromium 证据证明浏览器中 localStorage 写入失败时不会伪造 CAPA 知识样本入库。

## 影响

如果该路径失败时静默或显示成功，后续同类缺陷草案、CAPA 复用、知识库引用和审计回放都会基于不存在的样本证据继续推进。

## 处理

- 新增 e2e 注入真实浏览器 localStorage 写入异常。
- 断言 alert 明确展示 `质量知识样本写入失败`。
- 断言 UI 保留可重试入口，且本地证据不包含样本入库 trace。
