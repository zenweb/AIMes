# 2026-06-14 Issue - 排产优化缺少计划静默失败

## 问题
- `handleOptimize` 旧逻辑在优化接口返回成功但没有 `plan` 时，只结束 loading。
- 用户点击“排产优化”后看不到失败原因，当前甘特图也不会更新。
- 这会让调度员误以为优化已经被系统接受，实际排产计划仍停留在旧状态。

## 影响
- 用户关键路径：排产看板的一键优化。
- 风险类型：静默失败、后端契约异常不可见、优化结果误判。
- 严重性：中高，属于现有排产功能必须补齐的可靠性和可观察性缺口。

## 修复
- 当优化结果缺少 `plan` 时抛出明确错误：`后端优化结果缺少排产计划`。
- 复用既有错误展示路径，页面显示 `优化失败: 后端优化结果缺少排产计划`。
- 保持当前计划和指标不被异常结果覆盖。

## 验证
- 单测覆盖优化 200 响应缺少 `plan` 的 fail-loud 分支。
- Chromium 真实浏览器覆盖优化 API 返回无 `plan` 后页面告警和任务数量不变。
