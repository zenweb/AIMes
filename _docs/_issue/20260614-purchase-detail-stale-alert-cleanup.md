# 2026-06-14 Issue - Purchase 详情失败告警成功后残留

## 问题
- `PurchaseBoard.vue` 在启动证据同步失败时，会把启动告警与后续操作告警拼成同一个字符串。
- 采购订单详情加载失败后，如果后续成功选择另一张采购单，旧代码只在 `notification.startsWith('采购订单详情加载失败')` 时清空。
- 当启动告警在前时，详情失败告警不在字符串开头，成功选择后仍残留。

## 影响
- 用户已经打开新的采购详情后，页面仍提示上一张采购单详情加载失败。
- 这会降低采购协同关键路径的状态可信度，尤其是在启动证据 fail-loud 与人工继续操作并存时。

## 修复
- 新增 `operationNotification`，把当前操作告警从 `startupSyncFailures` 中拆出。
- `syncNotification()` 负责组合启动告警与当前操作告警。
- 采购详情成功加载时只清理当前详情失败操作告警，保留启动证据告警。

## 状态
- 已修复并验证通过。
