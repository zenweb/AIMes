# 2026-06-21 Issue - 生产开工刷新后丢失人员放行证据

## 现象
- 员工页已把停工复核放行为 `released`，并生成 `approved` 替班记录。
- 生产报工页面原本只读取 localStorage 的人员证据；刷新或新会话无法可靠读回后端放行结果。

## 根因
- 生产页没有在启动时拉取 `labor-reassignments` 与 `labor-qualification-blocks` 后端证据。
- 开工约束和开工确认只依赖本地同步函数。

## 修复
- 生产页新增后端人员证据缓存。
- 热处理开工约束优先本地即时记录，再查后端读回记录。
- 查询 active 阻断时显式排除 `released` 状态。

## 状态
- 已修复并通过单测、构建和真实浏览器验证。

## 独立遗留
- `POST /api/v1/production/scan` 对 `WO-013` 返回 400，需后续补齐生产扫描后端数据或调整演示工单与后端当前计划一致。
