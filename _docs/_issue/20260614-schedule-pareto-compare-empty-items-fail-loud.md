# 2026-06-14 Issue - 多目标对比成功但没有可比方案

## 问题
- `ParetoCompare.vue` 旧逻辑在 `batchOptimize` 返回 200 且 `items: []` 时，会进入普通空态。
- 对多目标排产优化来说，200 空方案不是有效业务结果，因为用户无法比较、无法采用、也无法形成排产反馈闭环。
- 这会让真实优化链路出现“请求成功但无可落地方案”的安静失败。

## 影响
- 用户关键路径：排产看板的多目标方案对比和方案采用。
- 风险类型：假成功、采用路径无结果、调度员缺少可行动原因。
- 严重性：中，属于现有排产功能必须补齐的可靠性缺口。

## 修复
- 当 `result.items.length === 0` 时抛出 `后端未返回可对比排产方案`。
- catch 分支展示 fail-loud 告警，并清空对比项、推荐目标和当前 tab。
- 单测和 Chromium e2e 均断言不展示普通空态、推荐卡或采用按钮。

## 验证
- 单测覆盖 200 空 `items` 必须 fail-loud。
- Chromium 真实浏览器覆盖 200 空 `items` 后弹窗展示失败告警。
- 完整排产 Chromium 套件和前端覆盖率总检均通过。
