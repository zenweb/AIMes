# Issue: Audit Replay 质量灰度决策失败被静默吞掉

日期：2026-06-06

## 问题

质量知识证据后端读取失败时，`queryQualityKnowledgeEvidence()` 捕获异常并返回空数组。审计回放面板无法区分“确实没有质量灰度决策记录”和“后端失败”，因此不会显示 `质量灰度决策加载失败`。

## 影响

- 用户会看到基础回放仍存在，但不知道质量灰度决策证据链读取失败。
- 发布就绪判断可能误把缺失证据当作无记录，违反 fail-loud 约定。

## 修复

- API 层停止吞错。
- backend-first 读取器统一处理：本地有有效记录时兜底；本地无有效记录时抛错给面板告警。
- 增加单测和真实 Chromium e2e 证据。

## 状态

- 已修复并验证。
- 发布 B 轨道闸门仍未关闭。
