# 2026-06-12 Issue：拖拽保存成功后结束时间未同步到本地甘特数据

## 问题

排产页拖拽任务并保存成功后，代码只更新了本地任务的 `start_date` 和 `duration`，没有同步 `end_date`。

## 影响

- 页面内后续读取同一任务窗口时，可能看到新的开始时间但缺少或沿用旧结束时间。
- 真实 dhtmlx 证据原先只证明发出了 PATCH 和显示“已更新”，不足以证明前端本地排产窗口完整一致。

## 修复

- 在 `handleTaskDragEnd` 保存成功分支中同步写回 `task.end_date = newEnd`。
- 单测断言拖拽保存后甘特数据包含新的开始时间和结束时间。
- E2E 断言 reschedule 请求形成有效且约 4 小时的排产窗口。

## 状态

已修复并通过定向验证。
