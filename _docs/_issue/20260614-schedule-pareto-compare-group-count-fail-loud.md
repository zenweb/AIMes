# 2026-06-14 Issue - 多目标对比分组数无效

## 问题
- `ParetoCompare.vue` 旧逻辑没有校验 `groupCount`。
- 当后端返回 `groupCount: -1` 时，页面会继续渲染推荐方案、KPI 表、雷达图和采用入口。
- 负数分组数不具备业务含义，会误导用户判断“分组少”的优劣。

## 影响
- 用户关键路径：排产看板的多目标方案对比和推荐方案采用。
- 风险类型：坏 KPI 展示、推荐依据污染、采纳动作缺少可信指标基础。
- 严重性：中，属于现有排产功能必须补齐的可靠性缺口。

## 修复
- 新增 `hasInvalidGroupCount`，要求 `groupCount` 为有限且非负。
- 当任一对比项分组数无效时抛出 `后端对比方案分组数无效`。
- 单测和 Chromium e2e 均断言不展示推荐卡或“采用此方案”入口。

## 验证
- 单测覆盖无效分组数必须 fail-loud。
- Chromium 真实浏览器覆盖无效分组数后弹窗展示失败告警。
- 完整排产 Chromium 套件和前端覆盖率总检均通过。
