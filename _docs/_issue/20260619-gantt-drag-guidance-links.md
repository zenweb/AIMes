# 20260619 Gantt Drag Guidance Links Issue

## 问题
甘特图支持拖拽排产任务，但拖拽前缺少本地中英双语提示，用户不容易在操作前核对锁定期、设备冲突、工序依赖和写回证据。

## 影响
- 调度员可能把拖拽当成普通视觉调整，而忽略其会触发排产窗口与写回证据变化。
- 排产、审计和报表之间的相关证据入口不够直接。
- 复杂操作缺少帮助锚点，不符合当前核心产品原则。

## 处理
- 新增 `#gantt-drag-help` 引导区。
- 增加 AI 排产、审计回放、报表证据、帮助四个入口。
- 将 `.gantt-e2e-markers` 通过 `aria-describedby` 关联到拖拽提示。

## 状态
- 已修复并完成目标测试、组件测试、全量覆盖率、lint、build、真实浏览器验证。
