# 2026-06-14 Issue - 推荐公式权重合计错误未精准暴露

## 问题
- 前端已经要求后端返回推荐公式元数据，但公式三项权重合计不等于 `1` 时，错误会被基础公式校验吞掉。
- 用户只能看到泛化的 `后端推荐公式说明缺失或无效`，不能判断问题是权重合计错误。

## 影响
- 推荐公式口径漂移时，错误不够可定位。
- 若后端返回 `40/30/20` 这类合计为 `0.9` 的权重，推荐卡不应继续展示为可采纳方案。

## 处理
- 将推荐公式基础校验与权重合计校验拆开。
- 权重合计不等于 `1` 时显示 `后端推荐公式权重合计无效`。
- 增加单测与真实 Chromium 回归证据。

## 状态
- 已关闭。
- 灰度 15 天观察按负责人指示跳过，不作为该 issue 阻塞项。
