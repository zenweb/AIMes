# 2026-06-14 Issue - 多目标对比后端失败展示演示推荐

## 问题
- `ParetoCompare.vue` 旧逻辑在 `batchOptimize` 抛错时直接 `loadDemoData()`。
- 当真实后端 503 或网络失败时，调度员看到的是可采用的 `综合平衡` 推荐，而不是失败原因。
- 这会把后端不可用伪装成一个有效多目标优化结果。

## 影响
- 用户关键路径：排产看板的多目标方案对比和方案采用。
- 风险类型：演示数据误采纳、正式推荐来源误判、审计链误导。
- 严重性：中高，属于现有排产功能必须补齐的可靠性和可审计性缺口。

## 修复
- 真实后端失败时设置 `error`，清空对比项、推荐目标和当前 tab。
- 错误区域加 `role="alert"`。
- 只有明确的离线演示错误继续加载 demo 推荐。

## 验证
- 单测覆盖真实后端失败不得展示推荐卡和采用按钮。
- 单测覆盖离线演示错误仍展示 demo 推荐。
- Chromium 真实浏览器覆盖 `optimize-compare` 503 后不可采用演示推荐。
