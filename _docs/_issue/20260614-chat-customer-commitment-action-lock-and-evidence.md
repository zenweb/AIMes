# 2026-06-14 Issue - 客户交付恢复承诺包可重复写入

## 问题

AI 生产助手的“生成客户交付恢复承诺包”成功后没有写入 `completedActionIds`。用户可以重复点击同一按钮，导致客户承诺包、审计记录与状态消息存在重复写入风险。

## 影响

- 证据链可能出现重复承诺包记录。
- 审计回放可能重复记录同一助手动作。
- UI 没有表达动作已完成，精品级体验不足。

## 修复

- 在 `customer_commitment_package` 成功写入承诺包后锁定当前 action id。
- 单元测试断言第二次点击不会再次调用写包、审计或跳转。
- 真实 Chromium e2e 断言按钮成功后禁用，同时保留跨报表、排产、审计证据检查。

## 状态

- 已修复并通过验证。
