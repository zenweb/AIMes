# 2026-06-14 Issue - 排产 Assistant 恢复闭环本地保存静默失败

## 问题
- `closeAssistantRecoveryHandoff(id)` 在 `closeAssistantRecoveryPackage` 返回空值时直接 `return`。
- 当本地恢复执行包缺失、损坏或无法持久化时，调度员点击“确认执行交接闭环”后没有任何反馈。
- 这会让用户误以为闭环动作已执行，实际既未闭环，也没有生成可审计的后续建议。

## 影响
- 用户关键路径：排产 Assistant 恢复交接闭环。
- 风险类型：静默失败、审计证据缺口、调度员误判。
- 严重性：中高，属于现有精品功能必须补齐的可观察性缺口。

## 修复
- 在空返回分支追加 `Assistant 恢复交接闭环保存失败，未找到可闭环的本地执行包：{id}`。
- 保持后续刷新、风险事件加载和闭环复核建议生成逻辑不变。

## 验证
- 单测覆盖本地保存失败分支。
- Chromium 真实浏览器覆盖远端恢复包存在但本地闭环记录缺失的交互路径。
