# 2026-06-14 Issue - 后端最新反馈缺少原因时仍被页面展示

## 问题
- 排产页已采用后端最新反馈优先、本地 snapshot 兜底。
- 但后端反馈若缺少 `reasonDetail` 等审计关键字段，旧逻辑仍会展示为正式最近反馈，并用 `未填写补充说明` 掩盖缺失。

## 影响
- 调度员和审计复盘可能看到不可解释的“正式反馈”。
- 本地 snapshot 中已有完整原因时，反而被不完整后端记录覆盖。

## 修复
- 增加后端反馈字段完整性校验。
- 缺少关键字段时，反馈面板展示 fail-loud 提示并回退本地 snapshot。
- 单测和 Chromium 均覆盖该场景。

## 剩余风险
- 后端接口自身仍需补契约测试，保证源头不产出不可审计反馈。
