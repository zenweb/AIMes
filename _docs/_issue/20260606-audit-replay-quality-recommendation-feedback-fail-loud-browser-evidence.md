# Issue: Audit Replay 质量推荐反馈失败态缺少真实浏览器证据

日期：2026-06-06

## 问题

质量推荐反馈是审计回放里解释“现场是否采纳推荐、效果趋势、下一轮训练集候选”的关键证据。此前共享读取器已具备后端失败且本地无记录时 fail-loud 的行为，但缺少该分支的独立真实 Chromium 证据。

## 影响

- 用户关键路径缺少浏览器级失败态证明。
- 质量推荐反馈证据链失败时，发布审计无法单独证明页面会保留基础回放并显式告警。

## 修复

- 新增真实 Chromium e2e，模拟 `QualityKnowledgeRecommendationFeedback` 后端 503。
- 新增单测，证明无本地质量推荐反馈记录时 backend-first reader 会抛错。

## 状态

- 已补证据并验证。
- 发布 B 轨道闸门仍未关闭。
