# 2026-06-06 Issue：返工排产动作缺少上下文语义

## 现象

- 返工排产事件生成按钮只有通用文本，未在可访问名称中暴露受影响的工单和检验号。
- 返工同步消息只是普通块，没有 `role="status"`。

## 影响

- 辅助技术用户无法稳定区分当前返工动作作用于哪张工单/检验记录。
- 决策生成后的跨模块同步反馈不具备状态播报语义，质量返工关键路径的精品级 UX 不足。

## 处理

- 为生成按钮补充 `生成 WO-003 INS-003 返工排产事件`。
- 为同步消息补充 `role="status"` 和 `aria-live="polite"`。
- 用 RED/GREEN 单测和真实 Chromium e2e 验证。
