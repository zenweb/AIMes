# 2026-06-21 Issue - 排产页刷新后可能使用本地 stale 人员阻断

## 现象
- 员工页已将人员阻断放行为 `released`，并写入 `approved` 替班记录。
- 排产页启动态原本可能继续从 localStorage 读取旧的 active 阻断，导致事件队列或 Agent 建议仍显示停工复核。

## 根因
- 排产页只有在生成某个 labor 事件建议时强制刷新后端证据；事件队列的初始构建仍可能依赖本地读取。

## 修复
- 排产页 `onMounted` 阶段读取后端人员阻断/替班证据。
- 后端成功时以后端为准，`released` 阻断不再回退本地 stale active。
- 新增单测锁定该行为。

## 状态
- 已修复并通过单测、构建和真实浏览器验证。
