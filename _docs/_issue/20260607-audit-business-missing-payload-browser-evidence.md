# 2026-06-07 Issue - 业务落库审计载荷缺失缺少真实浏览器证据

## 问题

`AuditDecisionReplayPanel` 已有单元测试覆盖业务落库审计载荷缺失，但缺少真实 Chromium 证据。

## 影响

缺失审计载荷如果在浏览器路径中被静默吞掉，会削弱发布签字、业务落库回放和审计可信度。

## 处理

- 新增 Chromium e2e 构造一条成功业务落库审计和一条 `newValues: null` 的缺失载荷审计。
- 验证页面保留成功采购落库回放。
- 验证 `.replay-sync-alert` 展示业务落库审计详情加载失败和具体缺失载荷编号。

## 状态

已通过定向单元测试和真实 Chromium e2e。
