# 2026-06-07 Issue - 扫码质量门释放写入失败 Chromium 证据

## 问题

扫码质量门复验放行已有单元测试覆盖写入失败，但缺少真实 Chromium 证据证明浏览器中 localStorage 写入失败时不会伪造放行结果。

## 影响

如果该路径失败时静默或显示成功，用户可能误以为 OP-20 接收、排产窗口和流转卡标签已恢复，导致 OTD 复盘和审计回放出现错误依据。

## 处理

- 新增 e2e 注入真实浏览器 localStorage 写入异常。
- 断言 alert 明确展示 `扫码质量门释放写入失败`。
- 断言 UI 保持待放行状态，且本地证据不包含 4 条放行 trace。
