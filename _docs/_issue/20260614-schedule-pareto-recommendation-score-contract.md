# 2026-06-14 Issue - 多目标推荐分数前后端双维护

## 问题
- 多目标推荐分数此前后端各维护一份公式。
- 后端用该分数选择 `bestOverallObjective`，前端又复算一次用于展示和一致性校验。
- 一旦公式变更只改一端，推荐卡可能显示错误综合分，或错误判断后端推荐不是最高分。

## 修复
- 后端 `ObjectiveCompareItemDto.RecommendationScore` 返回真实排序分数。
- 前端展示和最高分校验都使用后端分数。
- 缺少分数字段时前端 fail-loud。

## 剩余风险
- 当前响应只返回总分，分项贡献仍由前端按 KPI 文案解释。
- demo fallback 保留本地计算，需避免误用于真实后端路径。
