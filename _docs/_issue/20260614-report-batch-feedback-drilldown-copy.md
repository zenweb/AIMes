# 2026-06-14 Issue - 批量采纳钻取复用通用 Agent 推荐问题

## 问题
- 批量对比采纳 snapshot 已能进入报表 OTD 证据链。
- 但钻取列表仍把 `人工采纳` 证据显示成 `Agent 推荐为什么能提升 OTD？`，用户无法一眼区分这是采纳复盘而不是算法推荐解释。

## 影响
- 批量采纳证据卡可见，但钻取语义不够精品，降低复盘可信度。
- 后续审计时，用户需要从标题和摘要反推这是批量采纳，而不是从业务问题直接识别。

## 修复
- 为 `人工采纳` / `schedule-feedback` 证据增加专属钻取问题。
- 批量对比采纳显示 `批量对比采纳是否已进入 OTD 复盘？`。
- 详情区新增业务问题展示，并给出核对目标、原因、traceId 的下一步动作。

## 剩余风险
- 其它证据类型仍有部分通用文案，后续应按覆盖率杠杆和用户必经度逐片处理。
