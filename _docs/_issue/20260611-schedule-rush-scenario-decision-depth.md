# Issue：急单插单方案取舍解释不足

## 状态

已处理。

## 问题

原急单插单决策包能列出推荐方案和未选方案，但调度员无法直接看到每个方案的适用条件与取舍代价。采纳后 `reasonDetail` 也缺少这些信息，导致 OTD 复盘能知道选了什么，却较难解释为什么这个场景下应选它。

## 影响

- 调度员需要额外脑补锁定期、夜班窗口、换线成本和设备能力确认。
- 报表证据链对管理复盘的解释力不足。
- 多方案决策包容易退化成“看起来有三个方案”，但实际缺少可复盘的业务判断。

## 处理

- 给急单插单三方案补齐适用条件和取舍代价。
- UI、采纳反馈、后端提交和 OTD 证据链均保留这些信息。

## 验证

- 单测覆盖反馈快照与后端提交 payload。
- Chromium e2e 覆盖排产页、采纳反馈、本地快照和报表证据链。
- 真实浏览器截图覆盖排产页 `Agent 多方案决策包` 和报表页 OTD 证据链，证据清单位于 `output/playwright/20260611-schedule-rush-decision/manifest.md`。
