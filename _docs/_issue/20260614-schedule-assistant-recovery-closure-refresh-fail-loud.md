# 2026-06-14 Issue - 排产 Assistant 恢复交接闭环刷新失败静默兜底

## 问题
- 旧路径在 Assistant 恢复交接闭环后刷新恢复包时，会通过同步工具吞掉后端读取失败并回落本地数据。
- 用户无法区分“刷新成功但无变化”和“后端刷新失败但本地建议仍可用”。
- 对精品级排产闭环而言，这会削弱交接闭环的可观察性。

## 修复
- API 与同步工具增加显式 `failLoud` 模式。
- `ScheduleBoard.vue` 只在闭环后刷新路径启用 `failLoud`。
- 捕获刷新失败后显示原因，并保留本地闭环建议与 Agent 复核建议。

## 验收
- 单测确认 `failLoud` 会抛出后端错误。
- 组件测试确认闭环刷新失败时页面显示失败原因并保留建议。
- Chromium 真实浏览器确认后端 503 时页面保留闭环建议并提示原因。

## 状态
- 已修复并验证通过。
