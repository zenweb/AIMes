# 2026-06-14 Issue - 多目标对比计划项依赖不存在

## 问题
- `ParetoCompare.vue` 旧逻辑检查了计划项身份、时间窗、工单和设备锚点，但不检查 `dependentItems` 是否能在同一方案计划明细中找到对应任务。
- 当后端返回依赖不存在任务的计划项时，页面仍会展示推荐卡、KPI 表和“采用”按钮。
- 这会让依赖链断裂的方案进入采用路径，后续甘特图顺序、审计解释和回写链路缺少完整任务依据。

## 影响
- 用户关键路径：排产看板的多目标方案对比和推荐方案采用。
- 风险类型：假可落地方案、任务依赖链断裂、采用后执行顺序和审计说明不可信。
- 严重性：中高，属于现有排产功能必须补齐的可靠性和可审计性缺口。

## 修复
- 当任一计划项的 `dependentItems` 引用同一方案内不存在的任务 ID 时抛出 `后端对比方案计划项依赖不存在`。
- catch 分支沿用现有 fail-loud 告警，清空对比项、推荐目标和当前 tab。
- 单测和 Chromium e2e 均断言不展示推荐卡或“采用此方案”按钮。

## 验证
- 单测覆盖“计划项依赖指向不存在任务”必须 fail-loud。
- Chromium 真实浏览器覆盖该缺陷载荷后展示失败告警。
- 完整排产 Chromium 套件和前端覆盖率总检均通过。
