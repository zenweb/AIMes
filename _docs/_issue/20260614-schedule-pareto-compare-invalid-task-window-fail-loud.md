# 2026-06-14 Issue - 多目标对比计划项时间窗无效

## 问题
- `ParetoCompare.vue` 旧逻辑只检查计划项是否存在 `plannedStartTime` 和 `plannedEndTime`，不检查时间是否可解析或结束时间是否晚于开始时间。
- 当后端返回倒置时间窗时，页面仍会展示推荐卡、KPI 表和“采用”按钮。
- 这会让不可执行的任务时间窗口进入采用路径，后续甘特图和回写链路可能基于错误时间轴继续推进。

## 影响
- 用户关键路径：排产看板的多目标方案对比和推荐方案采用。
- 风险类型：假可落地方案、任务时间轴倒置、采用后反馈链基于无效排产窗口。
- 严重性：中高，属于现有排产功能必须补齐的可靠性和可审计性缺口。

## 修复
- 当任一计划项的开始或结束时间不可解析，或 `plannedEndTime <= plannedStartTime` 时抛出 `后端对比方案计划项时间窗无效`。
- catch 分支沿用现有 fail-loud 告警，清空对比项、推荐目标和当前 tab。
- 单测和 Chromium e2e 均断言不展示推荐卡或“采用此方案”按钮。

## 验证
- 单测覆盖“计划项时间窗倒置”必须 fail-loud。
- Chromium 真实浏览器覆盖该缺陷载荷后展示失败告警。
- 完整排产 Chromium 套件和前端覆盖率总检均通过。
