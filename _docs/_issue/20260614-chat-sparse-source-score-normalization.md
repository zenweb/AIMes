# 2026-06-14 Issue: ChatPanel 稀疏来源显示 NaN

## 问题
- 知识问答后端只校验 `sources` 是数组，未保证每条来源都有有效 `relevanceScore`。
- 当来源缺少分数字段时，参考来源区会显示 `NaN%`。

## 影响
- AI 生产助手的“参考来源”是用户判断回答可信度的关键证据入口。
- `NaN%` 会让证据展示显得不可信，并降低精品级体验。

## 修复
- 渲染前将非法或缺失分数归一为 `0`。
- 合法分数夹到 `0..1` 范围内。

## 状态
- 已修复并通过单测、Chromium e2e 和全量 unit coverage。
