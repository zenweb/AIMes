# Issue：无有效替班候选停工复核阻断证据

## 状态

已补 Chromium 证据，未发现当前路径的产品缺陷。

## 风险

当人员资质临期且没有有效替班候选时，如果系统继续生成替班建议或允许生产开工，会绕过人员能力约束，污染排产释放和 OTD 复盘。

## 证据

```powershell
npm.cmd run test:e2e -- tests/e2e/employee.spec.ts -g "无有效替班候选时生成停工复核阻断"
```

结果：`1 passed`。

## 当前表现

- 人员页显示无有效替班候选阻断原因。
- 不写入替班建议。
- 报表页展示人员阻断 OTD 证据。
- 审计页展示人员阻断回放和重新放行条件。
